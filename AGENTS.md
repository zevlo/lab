# AGENTS.md

## Git commits

All commits follow the Conventional Commits 1.0.0 spec: `type(scope): description`

- Types used in this repo: `feat`, `docs`, `fix`, `chore`, `refactor`
- Scope: the teaching topic or directory the change belongs to (`sec`, `k8s`, `docker`, `bash`, ...)
- Description: lowercase, imperative mood, no trailing period
- Examples from history: `docs(sec): record decay-type miss, schedule week-2 review as graduation`, `feat(docker): scaffold container teaching workspace with lesson 0001`
