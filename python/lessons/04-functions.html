Lesson 4

Functions

Package logic into reusable, testable units. This is what keeps scripts from becoming spaghetti.

Define & call

A function takes inputs (parameters), does work, and hands back a result with return.

def cpu_status(cpu):
    if cpu >= 90:
        return "critical"
    return "ok"

level = cpu_status(91)
print(f"status: {level}")
status: critical

return exits immediately. A function with no return gives back None.

Default values

Parameters can have defaults — callers only pass what differs. Very common in tooling: sensible defaults, full control when needed.

def deploy(app, env="staging", dry_run=False):
    mode = "dry-run" if dry_run else "live"
    print(f"deploying {app} to {env} ({mode})")

deploy("api")                       # uses both defaults
deploy("api", env="prod")
deploy("api", env="prod", dry_run=True)
deploying api to staging (live)
deploying api to prod (live)
deploying api to prod (dry-run)

Functions compose

Small functions call each other. Each does one thing — easy to read, easy to test, easy to reuse.

def needs_page(sev_counts, threshold=2):
    return sev_counts.get("ERROR", 0) >= threshold

print(needs_page({"ERROR": 3}))    # True
print(needs_page({"ERROR": 1}))    # False
Rule of thumb: copy-pasted a block for the second time? Make it a function. DevOps scripts grow fast — functions are how they stay maintainable.

def classify(line):
    if line.startswith("ERROR"):
        return "ERROR"
    elif line.startswith("WARN"):
        return "WARN"
    elif line.startswith("INFO"):
        return "INFO"
    return "???"

def count_severities(logs):
    counts = {}
    for line in logs:
        sev = classify(line)
        counts[sev] = counts.get(sev, 0) + 1
    return counts

def print_report(logs, error_threshold=2):
    counts = count_severities(logs)
    print(counts)
    if counts.get("ERROR", 0) >= error_threshold:
        print(f"ALERT: {counts['ERROR']} errors (threshold {error_threshold})")

logs = [
    "ERROR db-01 disk full",
    "INFO web-01 deployed v2.1",
    "WARN web-02 cpu at 85%",
    "ERROR db-01 query timeout",
    "INFO staging-01 backup done",
    "DEBUG cache hit ratio 0.98",
]

print_report(logs)
print_report(["INFO all good"])

Expected output:

{'ERROR': 2, 'INFO': 2, 'WARN': 1, '???': 1}
ALERT: 2 errors (threshold 2)
{'INFO': 1}
