Lesson 1

Variables & Types

Store data and format output. Every DevOps script starts here.

A variable is a label

Assign a value to a name. No type declarations — Python figures it out. Use # for comments.

name = "web-01"      # text (str)
cpus = 4            # whole number (int)
memory_gb = 16.5    # decimal (float)
is_prod = True      # boolean (bool): True or False

print(type(cpus))   # <class 'int'>

f-strings: format text

Gluing strings together with + is clunky. An f-string embeds variables directly — just prefix with f.

host = "web-01"
ip = "10.0.1.10"

print(f"{host} is at {ip}")
print(f"vCPUs with HT: {cpus * 2}")   # expressions work too
web-01 is at 10.0.1.10
vCPUs with HT: 8

Converting types

The string "4" is not the number 4. Data from files, input, and APIs arrives as strings — convert it explicitly.

count = int("4")        # str → int
version = str(3.11)     # float → str
ratio = float("0.98")   # str → float

print(int("20") + 1)    # 21 — math works
print("20" + "1")       # "201" — string concat, a classic bug
Why DevOps cares: server names, IPs, versions, sizes — scripts constantly mix text and numbers. f-strings and explicit conversion are 90% of the battle.
Exercise

Provisioning spec sheet

You are provisioning a new server. Start with these variables:

name = "web-01"
ip = "10.0.1.10"
cpus = 4
memory_gb = 16
region = "eu-west-1"
  1. Print a spec block (hint: the columns line up because of extra spaces inside the f-strings):
=== web-01 ===
IP:      10.0.1.10
CPUs:    4
Memory:  16 GB
Region:  eu-west-1
  1. Print a one-line summary: web-01 (10.0.1.10): 4 CPUs / 16 GB / eu-west-1
  2. RAM doubles next sprint. Print After upgrade: 32 GB — compute it from memory_gb, don't hardcode.
Runs real Python in your browser — your answer is saved automatically 
Output appears here when you press Run.
Hint

Everything can be an f-string: print(f"CPUs: {cpus}"). For step 3, multiply inside the braces: {memory_gb * 2}.

Show solution 
name = "web-01"
ip = "10.0.1.10"
cpus = 4
memory_gb = 16
region = "eu-west-1"

print(f"=== {name} ===")
print(f"IP:      {ip}")
print(f"CPUs:    {cpus}")
print(f"Memory:  {memory_gb} GB")
print(f"Region:  {region}")

print(f"{name} ({ip}): {cpus} CPUs / {memory_gb} GB / {region}")
print(f"After upgrade: {memory_gb * 2} GB")

Expected output:

=== web-01 ===
IP:      10.0.1.10
CPUs:    4
Memory:  16 GB
Region:  eu-west-1
web-01 (10.0.1.10): 4 CPUs / 16 GB / eu-west-1
After upgrade: 32 GB
