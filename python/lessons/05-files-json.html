Lesson 5

Files & JSON

Read configs, write reports. Real scripts talk to disk, not just the terminal.

Reading files

Always use with — it closes the file automatically, even on errors.

with open("app.log") as f:        # "r" (read) is the default mode
    content = f.read()           # whole file as one string

with open("app.log") as f:
    lines = f.readlines()        # list of lines (keepends=True → \n included)

Writing files

Mode "w" writes — and overwrites the file if it exists. Use "a" to append.

with open("report.txt", "w") as f:
    f.write("Server report\n")
    f.write("============\n")

JSON — the DevOps file format

Configs, API payloads, cloud CLI output: it's JSON everywhere. json.load turns a file into dicts and lists; json.dump writes them back.

import json

with open("servers.json") as f:
    data = json.load(f)              # file → dict/list

servers = data["servers"]
print(len(servers))                  # 5
print(servers[0]["name"])            # web-01

with open("backup.json", "w") as f:
    json.dump(data, f, indent=2)     # write back, pretty-printed

text = json.dumps(servers[0])        # obj → string (for logs/APIs)

Column alignment for reports

.ljust(width) pads a string with spaces to a fixed width — instant columns. (.rjust() right-aligns.)

print("web-01".ljust(12) + "cpu: 72%")
print("db-01".ljust(12) + "cpu: 91%")
web-01      cpu: 72%
db-01       cpu: 91%
Exercise

Generate a prod report

The file servers.json is preloaded into the browser sandbox — or save your script next to it and run locally with python3.

  1. Load servers.json and print the total number of servers.
  2. Build a list of only the servers where env is "prod".
  3. Write prod_report.txt: a header line PROD SERVERS (N), a line of = signs, then one line per prod server:
    name (ljust 12) + host (ljust 16) + cpu: N% — and append <-- HIGH CPU when cpu_usage is 80 or more.
  4. Print Report written: prod_report.txt (5 total, 4 prod).
Runs real Python in your browser — your answer is saved automatically 
Output appears here when you press Run.
Hint

Filter with a comprehension: prod = [s for s in servers if s["env"] == "prod"]. Build each line as a string first, append " <-- HIGH CPU" conditionally, then f.write(line + "\n"). "=" * 24 repeats a string.

Show solution 
import json

with open("servers.json") as f:
    servers = json.load(f)["servers"]

print(len(servers))

prod = [s for s in servers if s["env"] == "prod"]

with open("prod_report.txt", "w") as f:
    f.write(f"PROD SERVERS ({len(prod)})\n")
    f.write("=" * 24 + "\n")
    for s in prod:
        line = f"{s['name'].ljust(12)}{s['host'].ljust(16)}cpu: {s['cpu_usage']}%"
        if s["cpu_usage"] >= 80:
            line += "  <-- HIGH CPU"
        f.write(line + "\n")

print(f"Report written: prod_report.txt ({len(servers)} total, {len(prod)} prod)")

Expected terminal output:

5
Report written: prod_report.txt (5 total, 4 prod)

========================

db-01       localhost       cpu: 91%  <-- HIGH CPU
db-02       db-02.invalid   cpu: 8%
