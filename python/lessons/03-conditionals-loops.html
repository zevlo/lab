Lesson 3

Conditionals & Loops

Make decisions and process every item. This is how scripts read logs and check servers.

if / elif / else

Indentation (4 spaces) defines the block — there are no curly braces.

cpu = 91

if cpu >= 90:
    print("critical")
elif cpu >= 70:
    print("high")
else:
    print("ok")
critical

Comparisons & logic

Compare with == (equality — one = is assignment!), !=, <, >, <=, >=. Combine with and, or, not.

env = "prod"
cpu = 85

if env == "prod" and cpu > 80:
    print("page on-call")

for loops

A for loop visits every item in a list — no counters needed.

hosts = ["web-01", "web-02", "db-01"]

for host in hosts:
    print(f"checking {host}...")

for i, host in enumerate(hosts, start=1):
    print(f"{i}. {host}")
checking web-01...
checking web-02...
checking db-01...
1. web-01
2. web-02
3. db-01

Useful string checks

"db-01" in line tests substrings; line.startswith("ERROR") checks the prefix. Log parsing in two primitives.

line = "ERROR db-01 disk full"

line.startswith("ERROR")   # True
"db-01" in line            # True
Counting pattern: counts[key] = counts.get(key, 0) + 1 — read the old count (default 0), add one, store it back. Memorize this; you will use it constantly.
Exercise

Log triage

Given these log lines:

logs = [
    "ERROR db-01 disk full",
    "INFO web-01 deployed v2.1",
    "WARN web-02 cpu at 85%",
    "ERROR db-01 query timeout",
    "INFO staging-01 backup done",
    "DEBUG cache hit ratio 0.98",
]
  1. Print every line prefixed by its severity: [ERROR], [WARN], [INFO] — anything else gets [???].
  2. Count each severity into a dict (use the counting pattern) and print it.
  3. Print only the lines that mention db-01, prefixed with db-01 issue:.

Hint

Structure: one loop over logs. Inside, decide the severity with if/elif on line.startswith(...), store it in a variable like sev, print the tagged line, then update counts. Step 3 is a second, separate loop.

Show solution 
logs = [
    "ERROR db-01 disk full",
    "INFO web-01 deployed v2.1",
    "WARN web-02 cpu at 85%",
    "ERROR db-01 query timeout",
    "INFO staging-01 backup done",
    "DEBUG cache hit ratio 0.98",
]

counts = {}
for line in logs:
    if line.startswith("ERROR"):
        sev = "ERROR"
    elif line.startswith("WARN"):
        sev = "WARN"
    elif line.startswith("INFO"):
        sev = "INFO"
    else:
        sev = "???"
    print(f"[{sev}] {line}")
    counts[sev] = counts.get(sev, 0) + 1

print(counts)

for line in logs:
    if "db-01" in line:
        print("db-01 issue:", line)
