Lesson 6

Subprocess

Run shell commands from Python and act on the result. The capstone: a health-check script.

Run a command

Pass the command as a list of arguments — no quoting headaches, no shell injection.

import subprocess

result = subprocess.run(
    ["ping", "-c", "1", "127.0.0.1"],
    capture_output=True,    # capture stdout/stderr instead of printing
    text=True,              # get strings, not bytes
)

Inspect the result

Three attributes tell you everything. Convention: exit code 0 means success.

result.returncode    # 0 on success, non-zero on failure
result.stdout        # command output as a string
result.stderr        # error output

Fail loudly with check=True

With check=True, a non-zero exit raises CalledProcessError instead of silently continuing.

try / except — handling failure

Healthy scripts expect commands to fail and handle it. Catch the specific exceptions:

try:
    subprocess.run(
        ["ping", "-c", "1", "some.host"],
        capture_output=True, text=True, check=True, timeout=3,
    )
    print("reachable")
except subprocess.CalledProcessError:
    print("command failed (non-zero exit)")
except subprocess.TimeoutExpired:
    print("timed out")
Notes: on Windows, ping's count flag is -n instead of -c. And never pass untrusted input through shell=True — the argument list form is the safe default.
Exercise

Health-check script

Combine everything: JSON config + subprocess + error handling. Using servers.json from Lesson 5:

  1. Load the servers from servers.json.
  2. For each server, run ["ping", "-c", "1", host] with capture_output=True, check=True, and timeout=3.
  3. On success print [PASS] name; on CalledProcessError or TimeoutExpired print [FAIL] name (host).
  4. Finish with a summary: Healthy: 4/5.

Hint

Loop over the servers, try the ping inside the loop, and keep a passed counter incremented on success. The except clause can catch both exceptions in one tuple: except (subprocess.CalledProcessError, subprocess.TimeoutExpired):.

Show solution 
import json
import subprocess

with open("servers.json") as f:
    servers = json.load(f)["servers"]

passed = 0
for server in servers:
    try:
        subprocess.run(
            ["ping", "-c", "1", server["host"]],
            capture_output=True, check=True, timeout=3,
        )
        print(f"[PASS] {server['name']}")
        passed += 1
    except (subprocess.CalledProcessError, subprocess.TimeoutExpired):
        print(f"[FAIL] {server['name']} ({server['host']})")

print(f"\nHealthy: {passed}/{len(servers)}")

Expected output:

[PASS] web-01
[PASS] web-02
[PASS] staging-01
[PASS] db-01
[FAIL] db-02 (db-02.invalid)

Healthy: 4/5
