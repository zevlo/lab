Python for DevOps

The fundamentals, one concept at a time, each lesson built around a hands-on exercise with DevOps-flavored scenarios.

How to use: do the lessons in order — they build on each other, and Lesson 4 refactors Lesson 3. Type your answer in the editor under each exercise and press Run — it executes real Python right in your browser (first Run downloads the runtime, ~10 MB, once). Your answers save automatically. Solutions are hidden below the editor; peek only after attempting.
