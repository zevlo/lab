Lesson 2

Lists & Dicts

Collections hold your servers, logs, and config. These two types do almost all the work.

Lists — ordered collections

A list holds many values in order. Indexing starts at 0; negatives count from the end.

hosts = ["web-01", "web-02", "db-01"]

hosts[0]            # "web-01"  (first)
hosts[-1]           # "db-01"   (last)
len(hosts)          # 3
hosts.append("cache-01")   # add to the end
"db-01" in hosts    # True (membership test)
sorted(hosts)       # new sorted list

Dicts — labeled data

A dictionary maps keys to values. Think: one server's facts.

server = {"name": "web-01", "env": "prod", "cpu_usage": 72}

server["name"]              # "web-01"
server["cpu_usage"]         # 72
server.get("os", "unknown") # "unknown" — safe access with default
server["status"] = "up"     # add or update a key
server.keys()               # all keys
server.values()             # all values
Crash saver: server["os"] raises KeyError if the key is missing; server.get("os") returns None instead. Use .get() when a key might be absent.

Lists of dicts — the DevOps shape

Cloud APIs, CLI output, and JSON files all look like this: a list where each item is a dict describing one resource. Chain the lookups.

servers = [
    {"name": "web-01", "env": "prod",    "cpu_usage": 72},
    {"name": "web-02", "env": "prod",    "cpu_usage": 45},
    {"name": "staging-01", "env": "staging", "cpu_usage": 12},
]

servers[0]["name"]        # "web-01"
servers[2]["cpu_usage"]   # 12
