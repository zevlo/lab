# Starting from zero Python, with strong bash

The user has essentially no Python but is fluent in bash. Mission is interview readiness (writing Python from a blank file under observation), with short 15–20 minute sessions.

## Implications

- Every early concept can be anchored to a bash equivalent the user already knows (`$var` → variables, `for f in *; do` → `for` loops, `$(cmd)` → `subprocess`).
- Interview focus means retrieval practice from day one: the user should type code from memory, not copy-paste.
- Sequence fundamentals first (variables, strings, lists, dicts, loops, functions, files) before any DevOps tooling (subprocess, APIs, boto3).
