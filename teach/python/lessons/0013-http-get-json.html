HTTP GET and JSON

Fetch JSON from a URL — the interview task that turns file skills into API skills.

Recall first

From memory: what does json.loads(text) return, and when do you use it instead of json.load(f)? Check the reference after answering.

The one idea

Mission success includes “hit an API and process JSON.” You already parse JSON from files. An HTTP response is just bytes arriving over the network — open a URL, read the body, then json.loads the same way you would a string.

Python’s stdlib tool is urllib.request.urlopen. No package install. Interview-friendly.

import json
import urllib.request

url = "https://jsonplaceholder.typicode.com/todos/1"
with urllib.request.urlopen(url) as response:
    body = response.read()
    data = json.loads(body)

print(data["title"])

urlopen returns a file-like response. read() gives bytes. json.loads accepts those bytes and returns a dict (or list). Official docs: urlopen.

Guard the argument, then fetch

Same CLI pattern as Lesson 11: take the URL from sys.argv[1], refuse to run without it.

import json
import sys
import urllib.request
from urllib.error import HTTPError, URLError

if len(sys.argv) < 2:
    print("usage: fetch_json.py <url>")
    raise SystemExit(1)

url = sys.argv[1]

Network calls fail for real reasons — bad host, 404, offline. Catch the two you will see most:

try:
    with urllib.request.urlopen(url) as response:
        body = response.read()
        data = json.loads(body)
except HTTPError as e:
    print(f"error: HTTP {e.code}")
    raise SystemExit(1)
except URLError:
    print("error: could not reach URL")
    raise SystemExit(1)
except json.JSONDecodeError:
    print("error: response is not valid JSON")
    raise SystemExit(1)

print(data["title"])

HTTPError means the server answered with a failure status (404, 500, …). URLError means you never got a usable HTTP response (DNS fail, no network). Catch HTTPError before URLError — HTTPError is a subclass of URLError. See the official urllib HOWTO — Handling Exceptions.

Now type it for real

You need a network connection for this exercise.

From memory, create fetch_json.py in exercises/:

  1. Import json, sys, urllib.request, and HTTPError / URLError from urllib.error.
  2. If len(sys.argv) < 2, print usage: fetch_json.py <url> and exit with raise SystemExit(1).
  3. Set url = sys.argv[1].
  4. In a try: with urllib.request.urlopen(url) as response: read the body, then data = json.loads(body).
  5. except HTTPError as e: print error: HTTP <code> and exit 1.
  6. except URLError: print error: could not reach URL and exit 1.
  7. except json.JSONDecodeError: print error: response is not valid JSON and exit 1.
  8. Print data["title"].
  9. Run these three checks:
python3 fetch_json.py
python3 fetch_json.py https://jsonplaceholder.typicode.com/todos/1
python3 fetch_json.py https://jsonplaceholder.typicode.com/missing

Expected output:

usage: fetch_json.py <url>
delectus aut autem
error: HTTP 404
