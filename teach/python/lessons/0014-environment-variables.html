Environment Variables

Read config from the process environment — the usual place for URLs, env names, and secrets.

Recall first

From memory: after urlopen(url), what two steps turn the response into a Python dict? Check the reference after answering.

The one idea

Command-line arguments are great for “which file?” Environment variables are great for settings that change per machine or per deploy: API_URL, APP_ENV, tokens. Interview scripts often say “read this from the environment.”

In Python, the environment looks like a dictionary called os.environ:

import os

print(os.environ.get("HOME"))

Keys and values are strings. Official docs: os.environ.

Required vs optional

Two ways to read a variable — pick based on whether missing is allowed:

import os

# Optional: missing → None (or a default you provide)
env_name = os.environ.get("APP_ENV", "dev")

# Required: missing → KeyError (so check with .get and exit yourself)
api_url = os.environ.get("API_URL")
if api_url is None:
    print("error: API_URL is not set")
    raise SystemExit(1)

.get("KEY", "default") is the same idea as dict .get from earlier lessons. Use a default when a sensible fallback exists (dev). Require an explicit value when the script cannot run without it (API_URL).

Avoid bare os.environ["API_URL"] in interview scripts unless you want a raw KeyError traceback. A clear error message and exit code 1 reads better.

Put it together

import os

env_name = os.environ.get("APP_ENV", "dev")
api_url = os.environ.get("API_URL")

if api_url is None:
    print("error: API_URL is not set")
    raise SystemExit(1)

print(f"env: {env_name}")
print(f"url: {api_url}")

You set variables for one run by prefixing the command (shell syntax, not Python):

APP_ENV=prod API_URL=https://example.com python3 show_config.py

That is the whole skill: os.environ.get for optional-with-default, check for None when required, print or use the strings.

Now type it for real

From memory, create show_config.py:

  1. Import os.
  2. Set env_name = os.environ.get("APP_ENV", "dev").
  3. Set api_url = os.environ.get("API_URL").
  4. If api_url is None, print error: API_URL is not set and exit with code 1.
  5. Print env: <env_name> and url: <api_url>.
  6. Run these three checks:
python3 show_config.py
API_URL=https://example.com python3 show_config.py
APP_ENV=prod API_URL=https://api.example.com python3 show_config.py

Expected output:

error: API_URL is not set
env: dev
url: https://example.com
env: prod
url: https://api.example.com
