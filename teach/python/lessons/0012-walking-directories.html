Walking Directories

Find every matching file under a folder — including nested subfolders.

Recall first

From memory: what is sys.argv[1], and why check len(sys.argv) before reading it? Check the reference after answering.

The one idea

Interview prompts often ask you to scan a directory tree: find all .log files, list configs under /etc, count files by extension. You already open one file. Now you need every matching path under a root folder.

Python’s modern tool for this is pathlib.Path. A Path is an object that represents a filesystem location. Once you have one, you can ask it to walk itself:

from pathlib import Path

root = Path("sample")
for path in root.rglob("*.log"):
    print(path)

rglob means recursive glob: search this directory and every subdirectory for paths matching the pattern. The pattern "*.log" means “any name ending in .log.”

Official docs: Path.rglob.

Build a Path from an argument

Combine this with last lesson’s sys.argv. Turn the string argument into a Path, then check it is really a directory before walking:

import sys
from pathlib import Path

if len(sys.argv) < 2:
    print("usage: find_logs.py <directory>")
    raise SystemExit(1)

root = Path(sys.argv[1])
if not root.is_dir():
    print(f"error: not a directory: {root}")
    raise SystemExit(1)

root.is_dir() is True only when that path exists and is a directory. A missing path, or a plain file, both fail the check — same exit-code discipline you already use.

Walk and print matches

Once root is valid, loop with rglob. Each item is a Path; printing it shows the path as text:

for path in root.rglob("*.log"):
    if path.is_file():
        print(path)

The path.is_file() guard keeps the loop focused on real files. For a simple "*.log" pattern you will almost always get files anyway — but checking is a good habit when interviewers ask “what if a directory were named oddly?”

That is the whole skill: argument → Path → verify directory → rglob → act on each match.

Now type it for real

First, create this small directory tree (from the exercises/ folder is fine):

mkdir -p sample/web sample/db
echo "ok" > sample/app.log
echo "ok" > sample/web/access.log
echo "ok" > sample/db/query.log
echo "notes" > sample/db/notes.txt

Then, from memory, create find_logs.py:

  1. Import sys and Path from pathlib.
  2. If len(sys.argv) < 2, print usage: find_logs.py <directory> and exit with raise SystemExit(1).
  3. Build root = Path(sys.argv[1]).
  4. If not root.is_dir(), print error: not a directory: <root> and exit with code 1.
  5. Loop for path in root.rglob("*.log"):. If path.is_file(), print path.
  6. Run these three checks:
python3 find_logs.py
python3 find_logs.py sample
python3 find_logs.py missing

Expected output (paths may show as relative; order can vary):

usage: find_logs.py <directory>
sample/app.log
sample/web/access.log
sample/db/query.log
error: not a directory: missing

notes.txt must not appear — only .log files.
