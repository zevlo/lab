Scanning Logs Across a Tree

Glue skills you already have: walk a directory, open each log, count every ERROR.

Recall first

From memory: what does os.environ.get("APP_ENV", "dev") return when APP_ENV is unset? Check the reference after answering.

The one idea

Interview prompts rarely ask for one isolated trick. They ask for a short script that combines a few: “Given a directory, find all .log files and count lines containing ERROR.”

You already have every piece:

  • argv — which directory?
  • pathlib + rglob — which files?
  • open + line loop — read each file
  • string check — "ERROR" in line

Today’s skill is assembly: nest the file scan inside the walk, and keep one running total.

total = 0
for path in root.rglob("*.log"):
    if not path.is_file():
        continue
    with open(path) as f:
        for line in f:
            if "ERROR" in line:
                total = total + 1

Path objects work with open() — you do not need to convert them to strings first. Official file I/O: Tutorial — Reading and Writing Files. Walk refresher: Path.rglob.

Wrap it as a CLI tool

Same guards as Lesson 12, then the nested loops:

import sys
from pathlib import Path

if len(sys.argv) < 2:
    print("usage: count_tree_errors.py <directory>")
    raise SystemExit(1)

root = Path(sys.argv[1])
if not root.is_dir():
    print(f"error: not a directory: {root}")
    raise SystemExit(1)

total = 0
for path in root.rglob("*.log"):
    if not path.is_file():
        continue
    with open(path) as f:
        for line in f:
            if "ERROR" in line:
                total = total + 1

print(f"{total} errors found")

Outer loop = files. Inner loop = lines. One counter. That shape shows up constantly in DevOps take-homes.

Now type it for real

First, create this tree (from exercises/ is fine). Put real ERROR lines in the logs:

mkdir -p sample/web sample/db
printf 'INFO start\nERROR disk full\nINFO ok\nERROR timeout\n' > sample/app.log
printf 'INFO hit\nERROR 500\n' > sample/web/access.log
printf 'INFO query ok\n' > sample/db/query.log
echo 'not a log' > sample/db/notes.txt

That is 2 + 1 + 0 = 3 errors. notes.txt must be ignored.

Then, from memory, create count_tree_errors.py:

  1. Import sys and Path from pathlib.
  2. If no argv directory, print usage: count_tree_errors.py <directory> and exit 1.
  3. Build root = Path(sys.argv[1]). If not a directory, print error: not a directory: <root> and exit 1.
  4. Set total = 0. For each *.log file under root, open it and add 1 to total for every line containing "ERROR".
  5. Print <n> errors found.
  6. Run these three checks:
python3 count_tree_errors.py
python3 count_tree_errors.py sample
python3 count_tree_errors.py missing

Expected output:

usage: count_tree_errors.py <directory>
3 errors found
error: not a directory: missing
