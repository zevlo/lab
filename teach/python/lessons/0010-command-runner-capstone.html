Command Runner Capstone

One small script that reads JSON config, runs commands, and handles failure without blowing up.

Recall first

From memory: where does captured command output land after subprocess.run(..., capture_output=True, text=True)? And which exception catches broken JSON in json.load()? Check the reference after answering.

The one idea

Interview tasks rarely test one feature in isolation. They usually ask for a tiny script that combines several basics: read a config file, loop over items, run a command for each one, and handle the failures you can predict.

import json
import subprocess

with open("commands.json") as f:
    cfg = json.load(f)

for item in cfg["commands"]:
    result = subprocess.run(
        item["argv"],
        capture_output=True,
        text=True,
    )
    print(result.stdout.strip())

That skeleton is already most of the task. Lesson 0010 is about stitching together pieces you already know, not adding a lot of new syntax.

The config shape

Use JSON to describe what to run. Each command is a dict with a label and an argument list:

{
  "commands": [
    {"name": "say hi", "argv": ["echo", "hello"]},
    {"name": "show pwd", "argv": ["pwd"]}
  ]
}

The important detail is argv: it is a list of strings, exactly the shape subprocess.run() expects.

Success vs failure

A command can fail even when Python itself is fine. So this capstone checks result.returncode after each run and prints either the command's stdout or a short error line.

result = subprocess.run(
    ["echo", "hello"],
    capture_output=True,
    text=True,
)

if result.returncode == 0:
    print(result.stdout.strip())
else:
    print(f"error: command failed with code {result.returncode}")

Use try/except around the config-reading part, then use an if on returncode for each command. That separation is a good mental model: exceptions for Python/runtime failures, return codes for external program failures.

Now type it for real

First, create commands.json with this content:

{
  "commands": [
    {"name": "say hi", "argv": ["echo", "hello"]},
    {"name": "show pwd", "argv": ["pwd"]},
    {"name": "bad command", "argv": ["python3", "-c", "import sys; sys.exit(1)"]}
  ]
}

Then, from memory, create run_commands.py:

  1. Import json and subprocess.
  2. Wrap config loading in one try block: open commands.json, parse it with json.load(), store it in cfg.
  3. Add two except blocks: FileNotFoundError prints error: commands file not found; json.JSONDecodeError prints error: commands file is not valid JSON.
  4. Use an else: block after the exceptions. Inside it, loop over cfg["commands"].
  5. For each item, run item["argv"] with subprocess.run(..., capture_output=True, text=True).
  6. If result.returncode == 0, print <name>: <stdout> using item["name"] and result.stdout.strip().
  7. Otherwise print <name>: error code <number>.
  8. Run it and compare with the expected output below.

Expected output:

say hi: hello
show pwd: /your/current/directory
bad command: error code 1

The middle line will differ on your machine. That is fine.
