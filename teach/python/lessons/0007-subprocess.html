Running Commands

subprocess.run()

The standard library's subprocess module runs external commands. The one function you need for most DevOps scripts is subprocess.run():

import subprocess

result = subprocess.run(["echo", "hello"])
print(result.returncode)   # 0

Pass the command as a list of strings — program name first, then each argument. Python runs it, waits for it to finish, and gives you back a result object. No shell=True needed for simple commands, and a list is safer anyway.

Capturing output

By default, output goes straight to your terminal and Python can't see it. To capture it, add two keyword arguments:

result = subprocess.run(
    ["echo", "hello"],
    capture_output=True,
    text=True,
)

print(result.stdout)         # "hello\n"
print(result.stdout.strip()) # "hello"
  • capture_output=True — grab stdout and stderr instead of printing them.
  • text=True — return strings, not bytes. Without it, result.stdout is b"hello\n".

Command output usually ends with a trailing newline, just like file lines — .strip() again.

Exit codes

Every command exits with a number. 0 means success; anything else means failure. In Python it's result.returncode:

result = subprocess.run(["false"], capture_output=True)
print(result.returncode)   # 1 — command failed

if result.returncode != 0:
    print("command failed")

Add check=True and Python raises CalledProcessError automatically when the exit code isn't zero — useful when failure should stop your script immediately.
