Variables & Strings

The single biggest idea in Python: every value has a type.

The one idea

Every value in Python has a type: 5 is an integer you can do math with; "5" is a string of one character. They are different things, and Python refuses to silently mix them.

host = "web01"        # a string  (type: str)
cpu_count = 8         # an integer (type: int)
load = 2.75           # a decimal  (type: float)

print(host)           # web01
print(cpu_count * 2)  # 16

To use a variable, just name it: print(host) prints the variable's value, while print("host") prints the literal word host. Quotes make the difference between the thing named host and the text "host".

f-strings: putting variables inside text

To build a string that includes variable values, use an f-string: put an f before the opening quote, then wrap variables in curly braces.

host = "web01"
load = 2.75

print(f"load on {host} is {load}")
# load on web01 is 2.75

Forget the f and Python prints the braces literally — load on {host} is {load}. This is the #1 beginner typo. The braces can hold any expression: f"{cpu_count * 2} threads" works.

Crossing the type boundary

Python never converts between strings and numbers behind your back. You say it explicitly, with int(), float(), and str():

port = "8080"          # came from a config file, so it's a str
port + 1               # 💥 TypeError: can only concatenate str to str
int(port) + 1          # 8081  ✓

uptime_days = 42
"up for " + str(uptime_days) + " days"   # works, but clunky
f"up for {uptime_days} days"             # better — f-strings convert for you

Now type it for real

Open a terminal and run python3 to get the interactive shell (the >>> prompt — it runs each line as you type it). From memory, no peeking:

  1. Make a variable server holding "prod-web-01" and a variable connections holding 250.
  2. Print exactly: prod-web-01 has 250 connections — using both variables in one f-string.
  3. Double it: print at capacity: 500 using connections * 2 inside the f-string.
  4. Break it on purpose: type "5" + 1 and read the error message. Interviewers love asking what TypeError means — now you've seen one.
  5. Exit with exit().

If any step fails, the error message is the feedback — read it, fix it, rerun. That loop is the skill.
