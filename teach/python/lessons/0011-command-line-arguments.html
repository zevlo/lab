Command-Line Arguments

Pass a filename into a script so one program can work on many inputs.

Recall first

From memory: after a successful subprocess.run(..., capture_output=True, text=True), where does the command's text output land? And what does returncode == 0 mean? Check the reference after answering.

The one idea

Hardcoding "commands.json" or "app.log" inside a script works once. In interviews and real ops work, the same script usually needs to accept a path from the command line:

python3 count_errors.py app.log
python3 count_errors.py other.log

Python puts those words into a list called sys.argv. Index 0 is the script name; the arguments you care about start at index 1.

import sys

print(sys.argv)
# running: python3 count_errors.py app.log
# prints something like: ['count_errors.py', 'app.log']

So the filename is sys.argv[1]. That one value is enough to make a script reusable.

Check that an argument was given

If someone runs the script with no filename, sys.argv[1] does not exist and you get an IndexError. Guard with len(sys.argv) first:

import sys

if len(sys.argv) < 2:
    print("usage: count_errors.py <logfile>")
    raise SystemExit(1)

path = sys.argv[1]
print(f"reading: {path}")

raise SystemExit(1) stops the script with a nonzero exit code — the same idea as a failed command's return code. Exit code 0 means success; anything else means failure.

Use the path with skills you already have

Once you have path, open it like any other file. Combine this with the log-parsing loop from earlier lessons:

import sys

if len(sys.argv) < 2:
    print("usage: count_errors.py <logfile>")
    raise SystemExit(1)

path = sys.argv[1]
count = 0

try:
    with open(path) as f:
        for line in f:
            if "ERROR" in line:
                count = count + 1
except FileNotFoundError:
    print(f"error: file not found: {path}")
    raise SystemExit(1)

print(f"{count} errors found")

That pattern — read an argument, open that path, handle a missing file — shows up constantly in DevOps interview prompts.

Now type it for real

First, create a small log file named app.log:

INFO starting
ERROR disk full
INFO retrying
ERROR timeout
INFO done

Then, from memory, create count_errors.py:

  1. Import sys.
  2. If len(sys.argv) < 2, print usage: count_errors.py <logfile> and exit with raise SystemExit(1).
  3. Store sys.argv[1] in path.
  4. Set count = 0. Open path in a try block, loop over lines, and add 1 to count whenever "ERROR" appears in the line.
  5. On FileNotFoundError, print error: file not found: <path> and exit with code 1.
  6. After a successful read, print <n> errors found.
  7. Run these three checks:
python3 count_errors.py
python3 count_errors.py app.log
python3 count_errors.py missing.log

Expected output:

usage: count_errors.py <logfile>
2 errors found
error: file not found: missing.log
