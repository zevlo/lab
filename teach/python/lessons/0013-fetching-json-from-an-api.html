Fetching JSON from an API

Call an HTTP URL, parse the JSON body, and read fields from the result.

The one idea

You already know how to parse JSON from a file or a string. Interview prompts often skip the file and say: hit this API, then work with the response.

Python’s standard library can do that with no packages to install. urllib.request.urlopen fetches a URL and gives you back a response you can read — similar in spirit to opening a file:

from urllib.request import urlopen
import json

url = "https://jsonplaceholder.typicode.com/todos/1"
with urlopen(url) as response:
    body = response.read().decode()
    data = json.loads(body)

print(data["title"])

Three steps: open the URL, decode the bytes into text, parse that text as JSON into a dict (or list). After that, it is the same dictionary access you already use.

Official intro: HOWTO — Fetch Internet Resources Using urllib.

Take the URL from the command line

Same sys.argv pattern as before — the script should work on any URL you pass:

import sys
from urllib.request import urlopen
import json

if len(sys.argv) < 2:
    print("usage: fetch_todo.py <url>")
    raise SystemExit(1)

url = sys.argv[1]

Handle a failed request

Networks fail. Bad URLs fail. When urlopen cannot complete the request, it raises URLError (from urllib.error). Catch it the same way you catch FileNotFoundError:

from urllib.error import URLError

try:
    with urlopen(url) as response:
        body = response.read().decode()
        data = json.loads(body)
except URLError:
    print(f"error: could not fetch {url}")
    raise SystemExit(1)

print(f"title: {data['title']}")
print(f"completed: {data['completed']}")

URLError also covers many HTTP failures (like a 404), because HTTPError is a subclass of it. One except is enough for this lesson.

That is the whole skill: argument → urlopen → decode → json.loads → use the dict → catch URLError.

Now type it for real

You need a network connection for this exercise. From memory, create fetch_todo.py:

  1. Import sys, json, urlopen from urllib.request, and URLError from urllib.error.
  2. If len(sys.argv) < 2, print usage: fetch_todo.py <url> and exit with code 1.
  3. Store sys.argv[1] in url.
  4. In a try block: with urlopen(url) as response:, then body = response.read().decode(), then data = json.loads(body).
  5. On URLError, print error: could not fetch <url> and exit with code 1.
  6. Print title: <title> and completed: <completed> using data["title"] and data["completed"].
  7. Run these three checks:
python3 fetch_todo.py
python3 fetch_todo.py https://jsonplaceholder.typicode.com/todos/1
python3 fetch_todo.py https://jsonplaceholder.typicode.com/this-does-not-exist-404
