Variables, strings & types — Lesson 0001

TaskCodeNotes

Print a variableprint(host)no quotes — print("host") prints the literal word
Interpolate (f-string)f"on {host} now"the leading f is required; braces hold any expression

Every value has a type — "5" (str) and 5 (int) are different things, and Python refuses to silently mix them.

Just keys / valuesstatus.keys() / status.values()plain for k in status: loops keys
status = {"web01": "up", "web02": "up", "db01": "down"}

for host, state in status.items():
    print(f"{host}: {state}")

status["db01"] = "up"            # fixed it
print(status.get("web09", "unknown"))   # no crash: unknown

Mental model: a dict is a lookup table. Lists answer "what's item number 3?"; dicts answer "what's the value for this name?" — hostnames to states, config keys to settings, container names to images.
