Functions — Lesson 0005

TaskCodeNotes

Return a valuereturn f"ok: {host}"return ends the function immediately

def service_report(name, state):
    if state == "down":
        return f"ALERT: {name} is down"
    return f"ok: {name}"

msg = service_report("nginx", "up")
print(msg)                     # ok: nginx

Key distinction: print() shows a value to a human; return hands a value back to the code that called the function. A function that only prints can't have its result reused, tested, or written to a file.

import subprocess

result = subprocess.run(
    ["echo", "hello"],
    capture_output=True,

)

print(result.returncode)       # 0

Prefer a list of arguments over shell=True. A list avoids shell-injection bugs and is what interviewers expect.

Error handling — Lesson 0009

TaskCodeNotes
Try / excepttry: … / except FileNotFoundError:run fallback code instead of crashing
Missing fileexcept FileNotFoundError:open() on a path that doesn't exist
Bad JSONexcept json.JSONDecodeError:malformed text passed to json.load / loads
Missing dict keyexcept KeyError:cfg["key"] when key absent — prefer .get() for optional keys
Multiple handlersexcept A: … / except B: …first matching type wins; put specific before broad
import json

try:
    with open("config.json") as f:
        cfg = json.load(f)
    print(cfg["env"])
except FileNotFoundError:
    print("config missing")
except json.JSONDecodeError:
    print("config invalid")

Use try/except for operations that can fail at runtime (files, parsing, subprocess). Use .get() when a missing key is normal, not exceptional.

Capstone pattern — Lesson 0010

TaskCodeNotes
Load config safelytry: ... json.load(f) ... except ...catch file/JSON problems once, before the loop
Run configured commandsubprocess.run(item["argv"], ...)argv should already be a list of strings
Capture outputcapture_output=True, text=Truestdout lands in result.stdout
Check successif result.returncode == 0:0 means success, nonzero means failure
Print output cleanlyresult.stdout.strip()removes trailing newline from command output
import json
import subprocess

try:
    with open("commands.json") as f:
        cfg = json.load(f)
except FileNotFoundError:
    print("error: commands file not found")
except json.JSONDecodeError:
    print("error: commands file is not valid JSON")
else:
    for item in cfg["commands"]:
        result = subprocess.run(
            item["argv"],
            capture_output=True,
            text=True,
        )
        if result.returncode == 0:
            print(f"{item['name']}: {result.stdout.strip()}")
        else:
            print(f"{item['name']}: error code {result.returncode}")

from pathlib import Path

if len(sys.argv) < 2:
    print("usage: find_logs.py <directory>")
    raise SystemExit(1)

root = Path(sys.argv[1])
if not root.is_dir():

rglob = recursive glob. Pattern "*.ext" means any filename ending in that extension, at any depth under root.

Fetching JSON from an API — Lesson 0013

TaskCodeNotes

import sys
import json
from urllib.request import urlopen
from urllib.error import URLError

if len(sys.argv) < 2:
    print("usage: fetch_todo.py <url>")
    raise SystemExit(1)

url = sys.argv[1]

try:
    with urlopen(url) as response:
        body = response.read().decode()
        data = json.loads(body)
except URLError:
    print(f"error: could not fetch {url}")
    raise SystemExit(1)

print(f"title: {data['title']}")
print(f"completed: {data['completed']}")

Pattern: URL → urlopen → decode → json.loads → use the dict. Catch URLError for network/HTTP failures.

Scanning logs across a tree — Lesson 0015

TaskCodeNotes
Find log filesroot.rglob("*.log")same walk as Lesson 0012
Open each pathwith open(path) as f:Path works with open()
Count matchesif "ERROR" in line:same line scan as Lesson 0011
Accumulatetotal = total + 1one counter across all files
import sys
from pathlib import Path

if len(sys.argv) < 2:
    print("usage: count_tree_errors.py <directory>")
    raise SystemExit(1)

root = Path(sys.argv[1])
if not root.is_dir():
    print(f"error: not a directory: {root}")
    raise SystemExit(1)

total = 0
for path in root.rglob("*.log"):
    if not path.is_file():
        continue
    with open(path) as f:
        for line in f:
            if "ERROR" in line:
                total = total + 1

print(f"{total} errors found")

Interview pattern: walk → open each match → scan lines → one total. No new modules — glue skills you already have.
