Variables & strings — Lesson 0001

TaskBashPython
Assignhost="web01" (no spaces!)host = "web01" (spaces fine)
Use a variableecho "$host"print(host) (no $, no quotes)
Interpolate into stringecho "on $host now"print(f"on {host} now")
Numbers are real numbersn=5 (it's a string)n = 5 (a real integer)
Arithmeticecho $((n + 1))n + 1
String → numberautomatic-ishint("5"), float("1.5")
Number → stringautomaticstr(5)

Key mental shift: in bash everything is a string. In Python every value has a type — "5" and 5 are different things, and "5" + 1 is an error, not 6.

Key mental shift: no do/done. The colon plus indentation is the block. Everything indented under the for line is the loop body; the first unindented line is after the loop.
