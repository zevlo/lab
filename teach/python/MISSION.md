# Mission: Python for DevOps

## Why
Pass DevOps/SRE interviews that include Python coding rounds. The goal is to walk into an interview able to read, write, and reason about Python from scratch — not just tweak existing scripts.

## Success looks like
- Write a working Python script from a blank file in an interview setting (no autocomplete, no ChatGPT)
- Solve common DevOps interview tasks: parse a log file, hit an API and process JSON, walk a directory tree, run a shell command and handle its output
- Explain Python fundamentals out loud (data types, functions, error handling) when an interviewer probes
- Read unfamiliar Python — a CI script, a boto3 snippet — and say what it does

## Constraints
- Short sessions: 15–20 minutes each, so lessons must be tightly scoped
- Starting from zero Python; strong bash background to build bridges from
- Mixed environment at work (some cloud, some on-prem, lots of SSH and config files) — examples should be tool-agnostic where possible

## Out of scope
- Web frameworks (Flask, Django) — not what DevOps interviews test
- Deep OOP design patterns — only enough classes to read others' code
- Data science / ML libraries
