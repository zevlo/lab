Tests and coverage

python3 -m pytest
python3 -m coverage run -m pytest
python3 -m coverage report -m
python3 -m coverage html    # htmlcov/index.html

Unit / integration / functional. Regression tests lock a paid-for bug. Coverage is a map of untested lines, not a score to max. A test is good when a wrong return would fail it.

Hook and CI

# scripts/check and .git/hooks/pre-commit: put venv on PATH
root=$(git rev-parse --show-toplevel)
export PATH="$root/venv/bin:$PATH"
ruff format --check .
ruff check .
python3 -m pytest
A hook does not source bashrc. .git/hooks/ is local. The pre-commit framework is the committed-config version. CI runs the same commands in check-only mode on push, pull request, and sometimes a schedule. A matrix repeats across OS and language versions. CD publishes (Pages, wheels, images).
