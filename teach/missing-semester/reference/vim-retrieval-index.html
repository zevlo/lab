Workflow habits

  • Live in Normal. Esc (or Ctrl-[) when lost.
  • Arrive by name: / or f/t — not arrow keys or long hjkl runs.
  • Before Insert: name the sentence — operator + motion / text-object.
  • Undo / redo: u / Ctrl-r.
  • After a jump: Ctrl-o back (jump list).
