Steer, confirm, gate

Lecture 7: the agent loop and how you keep it honest. From Agentic Coding.

Loop

LLM samples a completion given a prompt (fixed context window). Chat resends the whole history. An agent adds tools (files, web, shell). The harness runs a tool after you confirm, then pastes the result back. You are the manager of an intern: spec, interrupt, review.

Default: the vendor can read this workspace (cloud inference; sometimes the whole repo). Confirm tool calls on the host.

Feedback loop

# let the agent run this, read output, edit, repeat
python3 -m py_compile file.py
python3 -m mypy file.py    # if installed in the venv
echo "status=$?"           # 0 = checkers clean; still read the diff

“Fix the mypy issues” works when the agent can invoke mypy. If it cannot, paste the artifact (lesson 0035).
