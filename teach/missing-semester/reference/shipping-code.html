Artifact and environment

Lecture 6: the file you ship and the machine it expects. From Packaging and Shipping Code.

Environment

python3 -m venv venv
source venv/bin/activate    # PATH gets venv/bin first
which python3               # .../venv/bin/python3
deactivate                  # function; restores PATH

Install with the venv’s pip. One venv per project. type deactivate shows the function; which deactivate looks only for files on PATH.

python3 -m pip install .

python3 -m pip freeze > requirements.lock

Versions and lock

SemVer MAJOR.MINOR.PATCH: breaking change, compatible feature, compatible bug fix. In 0.x, a minor bump can break callers. A library uses version ranges. An application locks the resolved set. pip freeze is a pin list. Hashed lockfiles such as uv.lock are stricter.

requests==2.32.3
click>=8.0
numpy>=1.24,<2.0
pandas~=2.1.0          # >=2.1.0 and <2.2.0

Copy the lockfile or manifest before the source so dependency layers stay cached. Keep secrets out of layers. Pin tags. Prefer slim bases.

Config and Compose

Same artifact, different environments: pass configuration at start time (environment variables, files). Raise if a required secret is missing. Compose DNS uses the service name (cache).

docker compose up --build
docker compose down
# web: REDIS_URL=redis://cache:6379
# cache: image redis:7-alpine
