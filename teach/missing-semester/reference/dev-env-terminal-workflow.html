Lecture 3 framing slice. Grounded in Development Environment and Tools.

MS: learn both a little; master at least one. This mission masters the terminal shape for DevOps / remote / no-GUI hosts.

Vim as the edit core

MS: most programming time is navigate / read / small edit — not long insert streams. Vim’s interface is a language: operators + motions + text objects (L0001–0005).

# MS “putting it all together” shape (see lesson drill)
G o … Esc          # end of file, open line, type, Normal
/range Enter 2w i  # search, move, insert
:6 Enter ci"       # line + change inside quotes
Defaults-only: no Caps Lock→Esc remaps, no plugin managers. Prefer Esc / Ctrl-[.

Beyond this slice

Language servers / LSP (and CLI checkers like formatters and type checkers); AI autocomplete / inline chat / agents; IDE extensions (dev containers, Remote SSH, Live Share). Skip installing a second IDE unless mission changes. Vim plugins stay out.
