Pareto shell commands

The ~20 commands that cover ~80% of DevOps terminal work on a bare bash stack. Prefer portable flags; check man / info on each host.

Five families

navigate  — where am I / move files
inspect   — read logs and pick lines
filter    — reshape streams in a pipeline
redirect  — send streams to files
ops       — processes and network (often remote Linux)

Navigate

CommandDoes
pwdPrint working directory
cdChange directory (cd - previous)
ls -laList including hidden; long form
mkdir -pMake dirs; create parents
cp -RCopy; recursive for dirs
mvMove or rename
rm -rfRemove; recursive + force (dangerous)
catConcatenate / dump small files
lessPage through a file (q quit)

Inspect

CommandDoes
head -n NFirst N lines
tail -n NLast N lines
tail -FFollow a log (survives rotate)
grep PATLines matching pattern
grep -v PATLines not matching

Filter (pipeline middle)

From Shotts’s redirection chapter: filters read stdin, write stdout. Chain with |.

CommandDoes
|Pipe stdout → next stdin
cut -d D -f NPick field N (delimiter D)
sortSort lines
sort -nrNumeric, reverse
uniqDrop adjacent duplicates (sort first)
uniq -cCount adjacent duplicates
wc -lCount lines
tee FILECopy stream to file and stdout
Mission recipe. Log triage shape: tail … | grep … | cut … | sort | uniq -c | sort -nr. uniq only collapses adjacent lines — always sort before uniq.

Redirect

OperatorDoes
> fileOverwrite file with stdout
>> fileAppend stdout to file
2>&1Merge stderr into stdout
cmd >f 2>&1Capture both streams in f

| connects programs. > connects a program to a file. Do not confuse them.

Ops (process + network)

CommandDoes
ps auxSnapshot of processes
pgrep -a NAMEFind PIDs by name
kill PIDSignal a process (default TERM)
kill -9 PIDForce kill (last resort)
curl -i URLHTTP request; show headers
dig NAMEDNS lookup
ss -tlnpListening TCP sockets (Linux)
macOS vs remote. ss is a Linux tool — use it on SSH remotes. Local Mac: reach for lsof -iTCP -sTCP:LISTEN or netstat when you must. Prefer portable flags when half your work is remote.

Canonical pipeline shape

source | narrow | extract | sort | count | rank
tail -F app.log \
  | grep ERROR \
  | cut -d' ' -f1 \
  | sort \
  | uniq -c \
  | sort -nr

Beyond the pareto

Useful later, not day-one muscle: find/xargs, sed/awk, jq, tar/gzip, deep chmod/chown, rsync, scp, ssh multiplexing, package managers. Add when a real incident demands them.

Primary: William Shotts, The Linux Command Line ch. 6 (redirection & filters); info coreutils; man bash (redirection). Lesson: 0007 — Pareto shell commands.
