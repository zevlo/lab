find, light sed, light awk

Lecture 1 “complicated tools” slice. Grounded in Introduction to the Shell.

find — locate by conditions

FormDoes
find DIR -type fFiles only (not dirs)
find DIR -type dDirectories only
find DIR -name '*.py'Basename glob (quote it!)
find DIR -exec CMD {} \;Run CMD per match; {} = path
 
find . -type f -name '*.py' -exec grep -l TODO {} \;
The \; ends -exec. Escape the semicolon so the shell does not eat it. Quote globs so the shell does not expand them early.

sed — substitute

sed 's/pattern/replacement/g' file     # preview → stdout
sed -i '' 's/pattern/replacement/g' file   # macOS / BSD in-place
sed -i 's/pattern/replacement/g' file      # Linux / GNU in-place
Always preview first. s = substitute; trailing g = all matches per line. macOS requires the empty extension '' after -i.

awk — columns

awk '{print $2}' file          # 2nd whitespace-separated field
awk -F, '{print $2}' file      # 2nd comma-separated field
awk '$2 > 100 {print $1}' file # filter rows, then print
$1, $2, … are fields; $0 is the whole line. Default FS is whitespace.
