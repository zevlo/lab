Light bash scripting

Lecture 1 “shell language” slice. Grounded in Introduction to the Shell.

Variables

name=value          # no spaces around =
echo "$name"        # expand; quote when unsure
name = value is not assignment — the shell runs a command named name.

Conditionals — if / test / [

if [ -f "$path" ]; then
  echo exists
else
  echo missing
fi

if [ "$a" = "$b" ]; then
  echo match
fi
FormDoes
[ -f path ]regular file exists
[ -d path ]directory exists
[ "$a" = "$b" ]string equality (quote)
Spaces after [ and before ] are required. Success = exit status 0.

Loops — for / while / $()

for h in web db cache; do
  echo "$h"
done

for i in $(seq 1 5); do
  echo "$i"
done

while [ -f /tmp/lock ]; do
  sleep 1
done
Prefer $(cmd) over backticks — nesting works. while repeats while the test command succeeds.

Scripts — shebang, set, args, chmod

#!/bin/bash
set -euo pipefail

# $1 = first argument
if [ -f "$1" ]; then
  echo "file exists: $1"
else
  echo "file missing: $1"
fi
PieceDoes
#!/bin/bashshebang — interpreter for ./script
set -eexit on command failure
set -uexit on undefined variable
set -o pipefailfail if any pipe stage fails
$1first argument ($0 = script name)
chmod +x script.shexecute bit for ./script.sh
bash script.sh ignores the need for +x. ./script.sh needs the execute bit so the kernel uses the shebang.

Handy one-liner

cp notes.txt "notes_$(date +%Y-%m-%d).txt"
