Arguments & globs

Lecture 2 Arguments slice. Grounded in Command-line Environment.

Positional parameters

FormMeaning
$0Program / script name
$1 … $9Positional arguments
$@ / "$@"All args; quote when forwarding
$#Number of positional args
Arguments are plain strings. The program decides flag vs operand meaning. Dash conventions (-a, --all, grouping -la) are social, not shell syntax.

Globs & braces

PatternDoes
*Any string (cwd; not recursive by default)
?Exactly one character
{a,b}Brace expansion → multiple words (text rewrite)
 
touch dir/{a,b,c}.py
ls dir/*.py
rm dir/?.py          # one-char names only
echo "*.py"          # literal — quotes suppress glob
The shell expands pathnames before exec. If matches exist, rm never sees the star. No match → pattern often left literal (default bash).
