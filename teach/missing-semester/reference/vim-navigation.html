Navigation

The pareto set: search, char-find, brace jump, marks, and the back button. Everything else is in Beyond the pareto at the bottom.

Search — /pattern n N

The single highest-leverage motion in vim. Get somewhere by name, not by counting lines.

KeyAction
/{pattern}<Enter>Search forward; cursor on first match
?{pattern}<Enter>Search backward
nNext match in current direction
NNext match in reverse direction
*Search forward for the word under cursor
#Search backward for the word under cursor
Pattern gotcha: ., *, [, ^, $, \ are regex metacharacters. To find a literal db.internal, escape the dot: /db\.internal<Enter>. In practice, the unescaped version often matches anyway (since . matches any char including a literal dot) — but escape it when precision matters.

Search composes as a motion. d/search<Enter> deletes from cursor to the next match. c?error<Enter> changes backward to "error".

Char on a line — f + ;

For landing on a specific column on the current line.

f{x}Forward to next {x}, cursor ON it
;Repeat last f/F/t/T (same direction)
Operators compose: df, deletes forward through the next comma. cf" changes forward to the next quote.

Brace matching — %

From a brace (( [ { ) ] }), jump to its match. Indispensable for JSON and embedded code blocks.

%Jump to matching brace
d%Delete from cursor to matching brace (inclusive)
v%Visually select from cursor to matching brace
Pair with text objects from the grammar reference: di{ clears a JSON object's contents; da{ removes the object and its braces.

Marks — bookmark a line

KeyAction
m{a-z}Set mark {a} at cursor (buffer-local)
m{A-Z}Set global mark (survives buffer switches)
'{a}Jump to first non-blank on mark {a}'s line
Devops idiom: set ma on the line you're editing, detour with /search to verify a related value, 'a snaps you back.

Jump list — the universal back button

Every jump (mark, search, G, etc.) is recorded. Walk back through your trail.

Ctrl-oJump back through the jump list
Ctrl-iJump forward through the jump list

Use this when you forgot to set a mark but need to get back.
