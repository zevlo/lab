Aliases & dotfiles

Lecture 2 Customizing the Shell slice. Grounded in Command-line Environment.

Dotfiles

Plain-text config files whose names start with . (hidden from bare ls). Common ones:

ToolTypical path
bash~/.bashrc, ~/.bash_profile
vim~/.vimrc
tmux~/.tmux.conf
ssh~/.ssh/config (L0024)
git~/.gitconfig
For bash on most systems, put interactive customizations in ~/.bashrc. Login shells often read ~/.bash_profile, which may source ~/.bashrc. Exact login/interactive matrix is deep — see bash man INVOCATION when it bites.

PATH in a startup file

export PATH="$PATH:/path/to/append"
Same export rule as L0022: children inherit the updated search path.

Aliases

alias ll='ls -lh'          # no spaces around =
alias gs='git status'
alias la='ls -A'
alias lla='la -l'          # compose

alias ll                   # print definition
\ls                        # bypass alias once
unalias ll                 # remove
alias name=value is a shell builtin taking one argument — spaces around = break it (same footgun family as host = db).

Persistence

# put durable aliases / exports in ~/.bashrc (or a file it sources)
source ~/.bashrc           # reload current shell after edits
