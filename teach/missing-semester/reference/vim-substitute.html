Substitute & the dot formula

Two workflows for changing many things at once: the :s family for bulk operations, cgn + . for surgical find-and-replace.

The :s family

CommandScope
:s/old/new/First match on the current line
:s/old/new/gAll matches on the current line
:%s/old/new/gAll matches in the whole file
:%s/old/new/gcAll matches, with per-match confirmation
Pattern is regex. Same metachar gotcha as search: . matches any char, * is a quantifier, etc. To match literally, escape: :%s/db\.internal/db-blue\.internal/g.

Word boundaries — the precision tool

Use \< and \> to anchor a match to word boundaries. Without them, :%s/api/edge/g would turn api-server into edge-server — sometimes wanted, often not.

\<api\>Matches api as a whole word; not inside api-server or api-server
\<apiWord starting with api
api\>Word ending with api

The confirmation prompt (:s/.../gc)

At each match vim asks replace with X (y/n/a/q/l/^E/^Y)?

yYes, replace this one and continue
nNo, skip this one and continue
aReplace all remaining without asking
qQuit without replacing this one
lReplace this one (last) and stop

The dot formula: . + cgn

The dot (.) repeats the last buffer-mutating change (insert, delete, change, etc.). Combined with gn (a motion that selects the next search match), you get the surgical find-and-replace workflow:

  1. /old<Enter> — search
  2. cgn — change the next match (the gn motion targets it)
  3. type replacement, Esc
  4. . — repeat the change at the next match
  5. n if you want to skip the next match without changing
This is Drew Neil's dot formula: one keystroke to move, one to execute, repeat with .. Faster than :%s/gc for medium-length lists, and each u undoes one change rather than the whole batch.

Dot repeat in general

. repeats the last change as a unit — including any motion that was part of it. This makes it a general-purpose power tool, not just for substitute:

  • x then j. — delete a char, move down, repeat delete
  • dw then j.j. — delete first word across three lines
  • >iw then j. — indent a word, repeat down a column

Beyond the pareto

Useful, but not in the lesson. Reach for these when a real need surfaces.
