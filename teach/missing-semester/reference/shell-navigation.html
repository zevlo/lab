Terminal vs shell

Terminal = the app that draws text (Ghostty). Shell = the program that reads commands (bash). You type into the terminal; bash interprets.

Prompt & cwd

ThingMeans
~Home directory
/Filesystem root
$ in promptOrdinary user (not root)
pwdPrint working directory
echo $PWDSame path via env var

cd & paths

CommandDoes
cd /pathAbsolute — from root
cd relRelative — from cwd
cd ~ or cdGo home
cd -Previous directory
.This directory
..Parent directory
cd is a shell builtin — not a separate program. A child process cannot change the parent’s cwd, so cd must live inside the shell (MS exercise).

PATH & which

echo $PATH          # :-separated search dirs
which echo          # where the shell finds echo
/bin/echo hi        # bypass PATH with full path

man

man ls              # full manual (q to quit)
ls --help           # short help on many commands
