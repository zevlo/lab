Environment variables & export

Lecture 2 Environment variables slice. Grounded in Command-line Environment.

Assignment & quotes

name=value          # no spaces around =
echo "$name"        # expands
echo '$name'        # literal $name
stamp=$(date +%F)   # command substitution
name = value runs a command named name. Convention: lowercase shell-local; ALL_CAPS for environment-facing names.

Shell-local vs environment

FormDoes
FOO=1Shell-local — children do not see it
FOO=1 cmdOne-shot env for cmd only
export FOO=1Put in environment — later children inherit
printenv / printenv FOOInspect the environment
unset FOORemove from shell (and env if exported)
 
TZ=Asia/Tokyo date
echo "${TZ-}"              # empty — one-shot did not stick

export DEBUG=1
bash -c 'echo $DEBUG'      # 1
unset DEBUG
