Memory profilers

Lecture 4 slice — heap over time with Valgrind massif + ms_print. Grounded in Debugging and Profiling.

Which question

ToolQuestion
Memcheck (L0034)At exit: was a pointer lost? (definitely / indirectly / possibly / still reachable)
free -h / htop (L0036)Whole-box RSS right now — not which function, not over the run
callgrind / perf (L0038)Which function is on the CPU
MassifHow heap size moved over the run, and which allocation sites owned it at the peak

A “space leak” Memcheck can miss: the pointer is still live (still reachable), the memory is unused, the heap never comes down. Massif’s graph is the tell.

Invocations (MS)

valgrind --tool=massif ./heap
ms_print massif.out.<pid>

# short programs — time unit = bytes alloc/free, not instructions:
valgrind --tool=massif --time-unit=B --massif-out-file=massif.out ./heap
ms_print massif.out

No summary on stderr — all data goes to the file. Compile with -g so trees name files and lines. No --privileged (that was perf_event in L0038).

ms_print graph

GlyphSnapshot
:normal — totals only
@detailed — allocation tree (default: every 10th)
#peak — also detailed; greatest recorded heap

Columns: n time total useful-heap extra-heap stacks. Useful = bytes the program asked for. Extra ≈ allocator admin + alignment (Massif’s default admin estimate is 8 B/block). Stacks stay 0 unless --stacks=yes (slow; off by default).

--time-unit= i (instructions, default — short programs look empty until the end) / ms (wall clock) / B (bytes alloc/free — reproducible; use this on tiny drills). Peak bars are taken after a deallocation; a program that never frees may show no #.

What Massif does not measure (default)

Heap via malloc/new and friends — not mmap/brk, not code/data/BSS, not the stack. Totals can sit well below htop RSS. --pages-as-heap=yes switches to page-level (named). massif-visualizer is the GUI (named, like kcachegrind).

Drill box

mkdir -p /tmp/ms-massif
docker run --rm -it -v /tmp/ms-massif:/work -w /work --name ms-massif debian bash
apt-get update && apt-get install -y gcc valgrind

Named only: Python memory-profiler (MS). Linux-only Valgrind — same as L0034; Mac has no Massif.
