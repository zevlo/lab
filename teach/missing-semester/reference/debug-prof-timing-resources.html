Timing and resource monitoring

Lecture 4 slice — the start of the Profiling half. Functionally correct can still be too expensive. Grounded in Debugging and Profiling.

The shift

Debugging asked whether the program is wrong. Profiling asks whether it is too expensive even when it is right. MS: find the hot spot (or the scarce resource) before optimizing — premature optimization is the root of all evil.

time (bash keyword)

type time          # shell keyword — not /usr/bin/time
help time
time curl https://missing.csail.mit.edu &> /dev/null
NumberMeans
realwall clock, start to finish — includes waiting
userCPU time in user code
sysCPU time in kernel code

MS curl: real 272 ms, user+sys 107 ms — the gap is network wait. Three diagnostic shapes: time sleep 1 (almost all real, ~0 CPU); a tight Python loop (real ≈ user+sys); curl (real ≫ user+sys). user+sys can exceed real on multiple cores (parallel CPU-bound). The keyword times a whole pipeline. /usr/bin/time is a different program (BSD on macOS, GNU on Linux).

Monitoring map

QuestionToolNotes
which process is hot (CPU / RAM)?htopLinux box; improved top. Mac ships top with different keys.
memory left for new work?free -hLinux only. Read available, not free.
who has this file open?lsof FILE / lsof -p PIDMac and Linux. htop l calls lsof for the selected process.
who is listening on this port?ss -tlnpLinux (L0010). Mac: lsof -nP -iTCP -sTCP:LISTEN.

free(1): free = currently unused; available = estimate for new apps without swapping (counts reclaimable cache). Linux caches aggressively — a small free on a healthy box is normal.

CPU affinity

nproc
taskset --cpu-list 0 stress -c 2

Two workers, one allowed CPU — they share core 0. N workers is a request; the affinity mask is the ceiling. MS writes taskset --cpu-list 0,2 stress -c 3 (three workers, two listed CPUs). Same idea; pinning to 0 alone always works. Linux-only (taskset(1), util-linux).

Occupied port (retrieval)

python3 -m http.server 4444
ss -tlnp | grep 4444
kill <PID>

MS profiling exercise; ss -tlnp is L0010. Mac cousin: lsof -nP -iTCP -sTCP:LISTEN.

Drill box

docker run --rm -it -p 4444:4444 --name ms-prof debian bash
apt-get update && apt-get install -y htop python3 procps iproute2 lsof stress

Second pane: docker exec -it ms-prof bash. time itself runs on the Mac (bash keyword). free / taskset / ss / htop are the Linux half.
