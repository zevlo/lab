Signals & job control

Lecture 2 Signals slice. Grounded in Command-line Environment.

Keyboard → signal

Key / commandSignalDoes
Ctrl-CSIGINTInterrupt foreground job
Ctrl-\SIGQUITQuit (stronger; may core-dump)
Ctrl-ZSIGTSTPSuspend (pause) job
kill pidSIGTERMGraceful terminate (default)
kill -KILL pidSIGKILLForce die — cannot be caught
close terminal / SSH dropSIGHUPHang up — children often die
kill -l lists signal names. Prefer TERM before KILL.

Job control builtins

FormDoes
jobsList unfinished jobs in this shell
fg / fg %NForeground (resume if suspended)
bg / bg %NContinue in background
cmd &Start already in background
kill %NSignal job number N
nohup cmd &Ignore SIGHUP; log to nohup.out
 
sleep 10000
# Ctrl-Z
bg
jobs
kill %1
%N is the bracket number from jobs, not a pid. Across shells, use pgrep -lf / pkill -f (Lesson 0008).

Survive disconnect

nohup long-running &     # resists SIGHUP; still one-shot
tmux new -s work         # durable interactive session (L0006+)
tmux detach (C-b d) / reattach is the DevOps default for remote work. nohup is the one-liner escape hatch.
