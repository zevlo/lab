Return codes

Lecture 2 Return codes slice. Grounded in Command-line Environment.

Convention

CodeMeans
0Success
nonzeroFailure / issue
 
true; echo $?     # 0
false; echo $?    # 1
ls /no/such; echo $?   # nonzero
$? is the exit status of the last command. Running echo $? replaces it with echo’s status (usually 0).

Short-circuit

FormRuns right side when…
cmd1 && cmd2cmd1 succeeded (0)
cmd1 || cmd2cmd1 failed (nonzero)
 
grep -q pattern file.txt && echo found
grep -q pattern file.txt || echo missing
true && echo always
false || echo always

Scripts & conditionals

exit 1              # leave script with failure status
# if / while use the same rule: 0 = true branch / keep looping
if [ -f notes.txt ]; then echo yes; fi
set -e (L0018) exits the script when a command returns nonzero — same convention, automatic.
