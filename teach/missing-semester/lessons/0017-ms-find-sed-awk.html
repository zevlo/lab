Lesson 0017 · Missing Semester — shell

find, light sed, light awk

Locate files, edit streams, extract columns — the MS “complicated tools” trio from lecture 1.

Why this matters

You can already compose line filters. Incidents also need “find every *.conf under here,” “rename a string in a file,” and “grab column 2.” Missing Semester introduces find, sed, and awk for exactly that — each is a language; today is the everyday subset.

Read first (10–15 min): MS Introduction to the Shell — the sed, find, and awk paragraphs under “What is available.” Skip the mega SSH pipeline and the bash scripting section for now.

Knowledge 1 — find

Recursive search with predicates. Quote globs. -exec … {} \; runs a command per match ({} = path; \; ends the action).

find . -type f -name '*.py'
find . -type f -name '*.py' -exec grep -l TODO {} \;
Quote the glob. Unquoted *.py expands in the current directory before find sees it. Always '*.py'.

Knowledge 2 — sed substitute

Most common form from MS: s/pattern/replacement/g. Preview to stdout first; only then edit in place.

sed 's/OLD/NEW/g' file              # safe preview
sed -i '' 's/OLD/NEW/g' file        # macOS / BSD in-place
sed -i 's/OLD/NEW/g' file           # Linux / GNU in-place
macOS -i needs ''. BSD sed treats the next argument as a backup extension. Empty string = no backup. On Linux remotes, drop the ''.

Knowledge 3 — awk columns

Default: split on whitespace; $1, $2, … are fields; $0 is the whole line. -F, for CSV-ish input.

awk '{print $2}' file
awk -F, '{print $1,$3}' file
awk '$2 > 100 {print $1}' file

Drill — scratch tree, then each tool

Ghostty + bash. Work under /tmp/ms-tree so nothing important gets hurt.

  1. Build the tree: 
    rm -rf /tmp/ms-tree
mkdir -p /tmp/ms-tree/scripts /tmp/ms-tree/logs
cat > /tmp/ms-tree/notes.txt <<'EOF'
status=draft
owner=ops
EOF
cat > /tmp/ms-tree/scripts/hello.py <<'EOF'
print("hello")
EOF
cat > /tmp/ms-tree/scripts/todo.py <<'EOF'
# TODO: harden auth
print("todo")
EOF
cat > /tmp/ms-tree/scripts/clean.py <<'EOF'
print("clean")
EOF
cat > /tmp/ms-tree/logs/access.log <<'EOF'
10.0.0.1 GET /health 200
10.0.0.2 GET /api 500
10.0.0.3 POST /login 401
10.0.0.2 GET /api 500
EOF
cat > /tmp/ms-tree/data.csv <<'EOF'
name,score,role
alice,50,dev
bob,150,ops
carol,200,ops
dave,80,dev
EOF
cd /tmp/ms-tree
pwd
    show answer

    cwd should be /tmp/ms-tree. Confirm with find . -type f | sort — five files under ., scripts/, logs/.

  2. find: 
    find . -type f
find . -type d
find . -type f -name '*.py'
find . -type f -name '*.py' -exec grep -l TODO {} \;
    show answer

    Three .py files. Only ./scripts/todo.py matches the TODO search. If you see a shell error about *.py, you forgot the quotes.

  3. sed — preview, then in-place (macOS form): 
    sed 's/draft/final/g' notes.txt
cat notes.txt
sed -i '' 's/draft/final/g' notes.txt
cat notes.txt
    show answer

    Preview prints status=final but the first cat still shows draft. After sed -i '', the file itself is updated. On a Linux remote you would use sed -i 's/draft/final/g' notes.txt (no '').

  4. sed again on the log (preview only — leave the file alone): 
    sed 's/GET/get/g' logs/access.log | head -n 2
    show answer

    First two lines show get instead of GET. Original file unchanged — confirm with grep GET logs/access.log.

  5. awk — whitespace then CSV: 
    awk '{print $1}' logs/access.log
awk '{print $4}' logs/access.log
awk -F, '{print $1}' data.csv
awk -F, '$2 > 100 {print $1,$3}' data.csv
    show answer

    IPs; status codes (200/500/…). CSV names; then bob ops and carol ops (scores > 100). Header line has non-numeric score — awk treats it as 0, so it drops out of $2 > 100.

  6. Compose: IPs that hit status 500, ranked (uses L0016 floor + awk): 
    awk '$4 == 500 {print $1}' logs/access.log \
  | sort | uniq -c | sort -nr
    show answer

    10.0.0.2 with count 2. awk narrows rows; your ranking recipe finishes the job.

  7. Cold rebuilds (no peeking) — from /tmp/ms-tree:
    1. List every .py file that contains TODO.
    2. Print names from data.csv whose score > 100.
    3. Preview-replace ops → sre in notes.txt (do not in-place yet).
    show answer

    (a) find . -type f -name '*.py' -exec grep -l TODO {} \;
    (b) awk -F, '$2 > 100 {print $1}' data.csv
    (c) sed 's/ops/sre/g' notes.txt

Check your understanding

Four questions. Shuffled answers.

Q1Why quote '*.py' in find?

  • stop early shell glob
  • find forbids bare stars
  • grep requires quotes
  • awk needs the quotes

Q2macOS in-place sed form?

  • sed -i '' 's/a/b/g' f
  • sed -i 's/a/b/g' f
  • sed --in 's/a/b/g' f
  • sed -I s/a/b/g f

Q3What is awk $2?

  • 2nd field this line
  • 2nd file argument
  • exit status code
  • parent directory

Q4In -exec … {} \;, what is {}?

  • matched file path
  • current $PATH
  • empty backup ext
  • awk field two
