Lesson 0013 · Phase 3 — tmux

Named sessions as workspaces

Stop living in one anonymous session. Name them, switch with C-b s, come back after an SSH drop by name.

Why this matters

Mission: survive disconnects and keep multi-host work organized. Lesson 0006 taught one session. Real ops needs several — e.g. ops (synced host panes), edit (vim), logs (long tail -F) — and a way to jump without tearing anything down.

Knowledge — one server, many sessions

From man tmux: a session is a persistent collection of windows. Your terminal is a client attached to one session at a time. Creating another session does not destroy the first.

tmux server (on this machine)
  ├── session ops
  ├── session edit
  └── session logs
Keys / commandDoes
tmux new -s nameCreate + attach named session
tmux new -s name -dCreate detached (don’t leave current)
tmux lsList sessions
tmux attach -t nameAttach from outside tmux
C-b sPick a session interactively
C-b ( / )Previous / next session
C-b LJump to last session
C-b $Rename current session
Name by job, not by number. ops / db / vpn beat 0 and 1. After an SSH drop: tmux ls → tmux attach -t ops.

Drill — two workspaces, switch both ways

If you are already inside tmux, detach first (C-b d) so the shell commands below run outside.

  1. Create an ops session and leave a marker: 
    tmux new -s ops
echo 'workspace: OPS' > /tmp/tmux-ops.txt
cat /tmp/tmux-ops.txt
    Detach with C-b d.
    show answer

    Status line should have shown session name ops. After detach you are back in plain bash; tmux ls still lists ops.

  2. Create a second session without leaving bash’s “outside” view — first make it detached, then attach: 
    tmux new -s edit -d
tmux ls
tmux attach -t edit
echo 'workspace: EDIT' > /tmp/tmux-edit.txt
    show answer

    tmux ls should list both ops and edit. You are attached to edit now.

  3. Switch with the picker: C-b s, arrow to ops, Enter. Confirm cat /tmp/tmux-ops.txt (or that you are in the pane where you created it).
    show answer

    C-b s is choose-tree filtered to sessions. Enter selects. Your edit session keeps running in the background.

  4. Flip with chords: C-b ) / C-b ( to cycle, then C-b L to jump back to the previous session.
    show answer

    L is “last session” — fastest toggle when you only bounce between two workspaces.

  5. Rename for clarity: in whichever session you’re in, C-b $, type a clearer name if needed (or keep ops/edit), Enter. Verify with tmux ls from a detached shell or C-b s.
    show answer

    Rename does not destroy windows or panes — only the label changes.

Pareto cut. Not today: kill-session, nested tmux, extra sockets. Leaving orphan sessions is fine until you intentionally clean up. Cheat sheet: multi-session.

  • lock the server

  • kills its windows
