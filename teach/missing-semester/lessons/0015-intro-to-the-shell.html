Introduction to the Shell

A terminal draws the prompt. A shell finds programs, connects their streams, and is itself a small language. Compose filters; do not memorize spells.

Why this matters

Missing Semester lecture 1 is how you live in a Unix machine: where you are, how programs are found, how you glue them, and just enough bash to put that in a file. The GUI cannot press a button that is not there. The shell can.

Knowledge 1 — where you are, how programs are found

Ghostty is the terminal (pixels). bash is the shell (parses a line, runs programs). date runs a program; echo hello is a program plus arguments. man date is the manual; --help is the short form.

cd is a builtin — it must run inside the shell process, or a child could not change the parent’s directory. Paths: / is the root; ~ is home; relative paths start from pwd. . is this directory, .. the parent.

$PATH is a colon-separated list of directories. The shell searches it for the first executable named like the command. which echo shows which file. An absolute path bypasses PATH. ls /bin is “what could I run.”

Knowledge 2 — compose streams; find, substitute, columns

Most filters take a file or read stdin. | connects stdout to the next stdin. > / >> write a file; tee does both. Stdout is fd 1; stderr is 2. Merge: cmd >f 2>&1 (order matters — not 2>&1 >f).

ToolJob
cat head tailprint / first / last lines
grep PATkeep matching lines
sort · uniq -corder lines; count adjacent dupes
find . -type f -name '*.py'recursive search; quote the glob
sed 's/old/new/g'substitute; preview, then in-place
awk '{print $2}'columns; -F, for CSV

Muscle: sort | uniq -c | sort -nr | head. uniq without sort is a lie.

macOS sed -i needs ''. sed -i '' 's/…/…/g' file (BSD). Linux remotes: sed -i 's/…/…/g'. Quote '*.py' for find -name so the shell does not expand it first. find … -exec cmd {} \; — {} is the path, \; ends the action.

Knowledge 3 — bash is a small language

host=db01              # no spaces around =
echo "$host"
if [ -f "$1" ]; then echo exists; else echo missing; fi
for i in $(seq 1 3); do echo "$i"; done

A script file starts with a shebang and usually a strict set:

#!/bin/bash
set -euo pipefail      # -e fail-fast; -u no unset; pipefail = failed stage fails the script
chmod +x check.sh
./check.sh notes.txt   # needs +x so the kernel honors the shebang; bash check.sh does not

$1 is the first argument; "$@" is all of them as a list. $(date +%Y-%m-%d) is command substitution (prefer over backticks).

Exercises

Missing Semester’s set, in order. Try before show answer. Pocket card after you struggle.

1 — ls -l

What does -l do? Run ls -l /. What do the first 10 characters of each line mean?

show answer

Long listing. First char = type (- file, d dir, l symlink). Next nine = rwx for user, group, other.

2 — globs

In find ~/Downloads -type f -name "*.zip" -mtime +30, what is a glob? Experiment:

mkdir -p /tmp/ms-shell/glob && cd /tmp/ms-shell/glob
touch a.txt b.txt c.txt file1.txt file2.txt file10.txt notes.md
ls *.txt
ls file?.txt
ls {a,b,c}.txt
show answer

A glob is a pathname pattern the shell expands before exec (* any string, ? one char, {a,b} brace). Quote "*.zip" so find matches it. file?.txt misses file10.txt.

3 — quoting

Difference between '…', "…", and $'…'? Echo a string with a literal $, a !, and a newline.

show answer

Single: literal. Double: expand $var / $(…). ANSI $'…': C escapes. echo $'literal $ and !\nand a newline'

4 — three streams

ls /nonexistent /tmp — stdout to one file, stderr to another. Then both to the same file.

show answer

ls /nonexistent /tmp >/tmp/ms-shell/out.txt 2>/tmp/ms-shell/err.txt
Both: ls /nonexistent /tmp >/tmp/ms-shell/both.txt 2>&1

5 — $?

Write a one-liner that creates /tmp/mydir only if it does not exist.

show answer

[ -d /tmp/mydir ] || mkdir /tmp/mydir — or mkdir -p /tmp/mydir.

6 — why cd is a builtin

show answer

A standalone cd would run in a child. Changing that child’s cwd cannot change the parent shell.

7–9 — check.sh, chmod, set -x

Script: argument $1, [ -f ], different messages. Run ./check.sh before and after chmod +x. Add -x to set and watch stderr.

show answer
cat > /tmp/ms-shell/check.sh <<'EOF'
#!/bin/bash
set -euo pipefail
if [ -f "$1" ]; then echo "exists: $1"; else echo "missing: $1"; fi
EOF
bash /tmp/ms-shell/check.sh /tmp/ms-shell/check.sh
chmod +x /tmp/ms-shell/check.sh
./check.sh somefile   # from that directory

Without +x, ./ is “Permission denied”; bash check.sh still works. set -x traces expanded commands to stderr.

10 — dated backup

Copy a file to notes_YYYY-MM-DD.txt.

show answer

11 — flaky runner takes a command

MS’s loop-until-fail script, but the test is "$@" instead of hardcoded cargo test. (No stress required.)

show answer
#!/bin/bash
set -euo pipefail
LOGFILE="test_runs_$(date +%s).log"
RUN=1
while "$@" > "$LOGFILE" 2>&1; do
  echo "Run $RUN passed"
  ((RUN++)) || true
done
echo "Failed on run $RUN"
tail -n 20 "$LOGFILE"

./flaky.sh true loops (Ctrl-C). "$@" keeps arguments separate.

Check your understanding

Four questions. Shuffled answers.

Q1Why is cd a builtin?

  • A child process cannot change the parent shell’s working directory
  • PATH never contains a cd binary on Unix
  • cd must run as root to touch /
  • man pages forbid external implementations

Q2POSIX merge of stdout and stderr into one file:

  • cmd >f 2>&1 — redirect stdout first, then point stderr at it
  • cmd 2>&1 >f — same effect, order never matters
  • cmd <f 2>&1 — stdin is where errors go
  • cmd >f 1>&2 — stdout already is stderr

Q3Why quote '*.py' for find -name?

  • So the shell does not expand the glob before find sees it
  • So find becomes case-insensitive
  • So brace expansion runs inside find
  • So find searches only the current directory

Q4uniq -c without sort first:

  • Counts only adjacent duplicates — unsorted input lies
  • Counts the whole file correctly; sort is cosmetic
  • Deletes every line; sort is required to print
  • Invokes awk internally, so order never matters
