Lesson 0027 · vim retrieval

Motions & workflow practice

No new keys. Mixed edits on a realistic config so search, text objects, marks, substitute, and visual mode feel like one workflow.

Why this matters

After L0026 you said the fizzbuzz compose pass felt fine, but motions and day-to-day workflow still do not feel natural. That gap closes with interleaved practice — not another lecture. This lesson only reuses L0001–0005 (plus the compose habits from L0026). Struggle first; open the retrieval index after you try.

Rules for this session. No arrow keys. Prefer /, f/t, %, marks, and text objects over long hjkl runs. Stay in Normal; enter Insert only for the typed replacement. Do not peek at Lessons 0001–0005 mid-drill.

Habits (recall, do not memorize new)

  1. Normal is home. Lost? Esc (or Ctrl-[), then decide the next sentence.
  2. Arrive by name. /pattern or f{x} beats scrolling.
  3. Speak the sentence. Operator + motion / text-object (ciw, ci", d%, >ip) before typing.
  4. Undo is cheap. u / Ctrl-r. After a jump, Ctrl-o returns.

Drill — one config, many edits

Ghostty + vim. Scratch: /tmp/vim-practice/. Create the file from bash (heredoc), then open it in vim and work the tasks in order. Reveal answers only after a real attempt.

mkdir -p /tmp/vim-practice && cd /tmp/vim-practice
cat > service.yaml <<'EOF'
apiVersion: v1
kind: Service
metadata:
  name: payments-api
  labels:
    app: payments
    env: staging
spec:
  type: ClusterIP
  ports:
    - name: http
      port: 8080
      targetPort: 8080
  selector:
    app: payments
---
# downstream: redis://cache.internal:6379/0
# owner: "platform-team"
# retry: 3
endpoints:
  - host: db-blue.internal
    role: primary
  - host: db-green.internal
    role: replica
EOF
vim service.yaml
  1. Jump to env: staging by search. Change the value to production with a text-object (not character-by-character Insert).
    show answer

    /staging then ciw → production → Esc. (Or land on the word and cw.)

  2. On the owner: comment line, change inside the quotes to sre-oncall.
    show answer

    /owner (or f" on that line) → cursor inside quotes → ci" → sre-oncall → Esc.

  3. Change both 8080 ports to 8443. Prefer one composed approach (:%s or cgn + .).
    show answer

    :%s/8080/8443/g then Enter. Or /8080 → cgn → 8443 → Esc → . for the second.

  4. Mark the endpoints: line with mark e. Jump to the top with gg, then return with 'e.
    show answer

    On endpoints:: me. Then gg, then 'e. Optional: Ctrl-o also walks the jump list backward.

  5. On the primary host line, change db-blue.internal to db-amber.internal using an in-line find (f/t) plus a change — avoid holding l.
    show answer

    On that line: f. or /blue → ciw on blue → amber → Esc. Or ct. / cf. shapes if you prefer “change to/find” from the start of the hostname.

  6. Visual-line select the two endpoints host entries and yank them to register a. Paste below the block once with "ap (you can u afterward — the point is the register move).
    show answer

    On first - host:: V → j (or motion to cover both lines) → "ay. Move below → "ap. Undo with u if you want a clean file.

  7. Optional local clipboard: yank the name: payments-api line to the system clipboard with "+, paste somewhere outside vim (Notes / browser) to confirm.
    show answer

    On the line: "+yy (or V"+y). Remote SSH: system clipboard may not follow — use tmux copy-mode instead (L0005 / L0011).

  8. Cold rebuild (close vim, reopen the same file or recreate it). From memory, no peeking at this page:
    1. Change staging → production with a text-object.
    2. Change inside the owner quotes.
    3. Replace both port numbers in one go.
    4. One sentence out loud: what do you do the moment you feel lost in a mode?
    show answer

    (a) /staging → ciw … Esc
    (b) ci" on the owner line
    (c) :%s/8080/8443/g or cgn+.
    (d) Hit Esc, return to Normal, then name the next sentence.

Check your understanding

Six interleaved questions. Answers shuffled on each load.

Q1Best default when you feel lost in vim?

  • Esc back to Normal
  • mash arrow keys
  • quit with kill -9
  • open Insert and type

Q2Change the word under the cursor?

  • ciw
  • dd
  • gg
  • Ctrl-o

Q3Change inside a double-quoted string?

  • ci"
  • diw
  • yy
  • :q!

Q4Jump back after a search or mark jump?

  • Ctrl-o
  • Ctrl-c
  • Shift-z
  • Alt-Left

Q5Repeat the last change on the next search hit?

  • cgn then .
  • dd then p
  • v$ then x
  • :w then :e

Q6Yank the current line into register a?

  • "ayy
  • :reg a
  • ma then 'a
  • "+p
