Lesson 0011 · Phase 3 — tmux

Scrollback, yank, paste

Enter copy-mode, grab text into the tmux buffer, paste with C-b ]. Portable remote skill — not the macOS clipboard.

Why this matters

Mission needs mouse-free capture of output that already scrolled off screen — especially over SSH. Hierarchy (Lesson 0006) is fluent; this is the deferred copy-mode slice. On your Mac, yank stays in the tmux buffer; train that path so remotes behave the same.

Knowledge 2 — enter, yank, paste

From man tmux: C-b [ runs copy-mode; C-b ] runs paste-buffer. Stock mode-keys is emacs unless EDITOR/VISUAL contains vi. Confirm: tmux show -g mode-keys.

KeysDoes
C-b [Enter copy-mode
arrows / PgUp PgDnMove in scrollback
C-SpaceBegin selection (emacs)
C-wCopy to tmux buffer; exit (Meta-free — prefer on Mac)
M-w / Option-wSame copy — needs Option-as-Meta in the terminal
q or EscLeave without copying
C-b ]Paste top buffer into pane
This Mac (mandatory) — buffer ≠ pasteboard. A successful yank fills the tmux paste buffer only. It does not put text on the macOS clipboard for Notes/browser. Portable proof: tmux show-buffer then C-b ].
This Mac — Option is not Meta by default. Stock Ghostty/Terminal leave Option for special characters, so Option-w never reaches tmux as M-w and yank appears “broken.” Meta-free yank (no config): after C-Space selection, press C-w (also bound to copy). Or with your mouse on: enter copy-mode, drag to select, release — that yanks. Durable Ghostty fix: macos-option-as-alt = left so left Option sends Alt/Meta.
C-Space may be stolen. macOS often uses Control-Space for input-source switching. If begin-selection does nothing, check System Settings → Keyboard → Keyboard Shortcuts → Input Sources, or start the selection with a mouse drag instead.
vi mode on some remotes. If mode-keys is vi: Space begins selection, Enter copies. Same C-b [ / C-b ] outside.

Drill — yank a token, paste it back

In Ghostty, use a tmux session (create one if needed: tmux new -s copydrill).

  1. Generate scrollback and a unique token: 
    seq 1 80
echo "TOKEN-$(date +%s)-COPYMODE"
    Note the TOKEN-… line — you will yank it.
    show answer

    seq pushes earlier lines off the visible screen so copy-mode has somewhere to scroll. The echo line is your target string.

  2. Enter copy-mode (C-b [). Page/arrow until the TOKEN-… line is visible. Place the cursor on it.
    show answer

    Status line usually indicates copy-mode. If keys do nothing useful, you may not have entered — press prefix then [ again.

  3. Select and yank (emacs defaults). Prefer C-w on Mac until Option-as-Meta is configured: 
    C-Space     # begin selection (if macOS steals this, mouse-drag instead)
# move to cover the whole TOKEN line
C-w         # copy to tmux buffer, exit (Meta-free)
# Option-w  # only works after macos-option-as-alt / Option-as-Meta
    Verify: 
    tmux show-buffer
    show answer

    show-buffer must print your TOKEN-… text. If empty, selection/yank failed — usually Meta never arrived, or C-Space never began a selection. Mouse-drag in copy-mode is a reliable fallback with mouse on. Do not expect Notes/pasteboard to update.

  4. Paste into the shell with C-b ], then press Enter if needed so the line runs as a command or sits on the prompt. Confirm the token reappeared.
    show answer

    Paste inserts buffer text at the cursor. This is the remote-portable loop: scroll → select → yank → C-b ].

  5. Optional: exit copy-mode with q without yanking once, to feel the difference from Option-w.
    show answer

    q/Esc leaves; buffer unchanged. Yank only happens on the copy key.
