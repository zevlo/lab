Lesson 0006 · tmux

tmux

A session is a place that survives the client. Windows are tabs; panes are splits; copy-mode is the scrollback that exists on a bare remote.

Why this matters

Close Ghostty, lose SSH, sleep the laptop — a process in a raw shell dies (SIGHUP). tmux keeps a server of sessions on the machine. Missing Semester’s multiplexer section is this hierarchy plus detach/reattach. This file is that, plus the daily keys: copy-mode, sync-panes, named workspaces. Defaults only.

Read first (≈10 min): man tmux DESCRIPTION and DEFAULT KEY BINDINGS. Skim MS Terminal Multiplexers.

This is the whole tmux floor. Spread sittings. Prefix is Ctrl-b, then release, then the key — not all three at once. Your local conf may set base-index 1; stock remotes start at 0. Train C-b 0 for strangers’ machines.

Knowledge 1 — hierarchy and the daily keys

session  (survives detach / SSH drop)
  └── window  (a tab — full screen)
        └── pane   (a split — one pty)

The terminal is a client attached to one session. Detach ≠ kill.

WhereCommand
shelltmux new -s ops · tmux ls · tmux attach -t ops
detach / windowsC-b d · c new · n/p next/prev · 0–9 by index
panesC-b % left/right · " top/bottom · o cycle · arrows · z zoom · x kill
sessionsC-b s picker · (/) prev/next · L last · $ rename
helpC-b ?

Name sessions by job (ops, edit), not by number. tmux new -s name -d creates without leaving the current client.

This Mac — buffer ≠ pasteboard. Yank fills the tmux paste buffer. Prove it with tmux show-buffer then C-b ]. It does not put text on the macOS clipboard. Option is not Meta in stock Ghostty, so Option-w is not M-w — use C-w after C-Space, or mouse-drag in copy-mode. If C-Space is stolen by input-source switching, use the mouse. Vi mode on some remotes: Space begins, Enter copies.

Knowledge 3 — sync-panes and many sessions

No default key for synchronize. Command prompt: C-b : then setw synchronize-panes on (or off / toggle with no argument). Window-scoped: only panes in this window. Habit: on → burst → off before exploratory typing. Real use: several SSH panes, identical triage, then off.

One tmux server, many sessions. After an SSH drop: tmux ls then tmux attach -t ops.

Setup

tmux -V   # this machine: 3.7b
# If already attached: C-b d first so the drills’ shell commands run outside tmux.

Exercises

Ghostty. Try before show answer.

1 — Abandon and reclaim

tmux new -s drill
# C-b % then C-b "  → three panes; C-b o; hostname in each
# C-b z zoom, C-b z unzoom
# C-b c second window; C-b n / p
# C-b d
tmux ls
tmux attach -t drill

Are both windows and the pane layout intact?

show answer

Yes — that is the SSH-drop story, practiced locally. Status line should show drill and two windows. Window numbers depend on base-index.

2 — Yank a token

In the session:

seq 1 80
echo "TOKEN-$(date +%s)-COPYMODE"

C-b [, land on the TOKEN line, select, C-w. Prove with tmux show-buffer and C-b ]. Did Notes.app get the string?

show answer

Buffer has the token; C-b ] pastes into the pane. Notes.app does not, unless you used Ghostty mouse copy. That is the Mac caveat, not a failed yank.

3 — Sync, then off

Three panes, different prompts (export PS1='A> ' etc.). C-b : setw synchronize-panes on. Type date — all three run it. Then off, type in one pane only.

show answer

On: every pane gets the keystrokes. Off: only the focused pane. Leave it off.

4 — Two workspaces

tmux new -s ops
# leave a marker file, C-b d
tmux new -s edit
# C-b s  (or C-b L) to jump back to ops

Both sessions still listed after you detach?

show answer

tmux ls shows ops and edit. C-b L toggles last session; C-b s picks by name.

Check your understanding

Four questions. Shuffled answers.

Q1What survives an SSH drop?

  • The tmux session on the remote — reattach with tmux attach -t name
  • Only processes started with & in that SSH shell
  • Ghostty’s scrollback, forwarded automatically
  • Nothing — SIGHUP always kills the remote tmux server

Q2On this Mac, a copy-mode yank goes to:

  • The tmux paste buffer — paste with C-b ]
  • The macOS clipboard, always, via Option-w
  • Vim register + only
  • bash history, as a comment

Q3synchronize-panes is:

  • A window option, toggled with C-b : — no default prefix chord
  • C-b S, bound by default on every tmux
  • Server-wide: every session’s panes type together
  • The same as zoom (C-b z)

Q4Stock remotes number the first window:

  • 0 — C-b 0; local conf may use base-index 1
  • 1 everywhere; 0 is never a window
  • By session name, not a number
  • Only after you rename with C-b $
