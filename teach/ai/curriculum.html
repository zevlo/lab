NCP-AIO Depth-First Curriculum

A small-lesson path to become a strong AI Infrastructure Engineer while preparing for the NVIDIA-Certified Professional: AI Operations exam. The official NVIDIA four-domain blueprint is canonical; the method is hardware-first, operations-aware, and hands-on whenever the lab allows it.

Start here: Lesson 1: GPU Baseline Diagnostic · Reference: Glossary · Sources: RESOURCES.md

Operating Model

Depth First

Every operational command should connect to the mechanism beneath it: silicon, memory hierarchy, PCIe, drivers, containers, schedulers, fabric, and failure modes.

Small Wins

Each lesson teaches one tight concept and produces one artifact: a diagnostic result, mental model, mini-runbook, config, or explanation.

Retrieval

Lessons ask you to predict, recall, classify, or diagnose before showing the explanation. Fluency is not mastery; storage strength is the target.

Foundation Strands

Silicon To Scheduler

GPU architecture, SMs, warps, registers, HBM/GDDR, PCIe, DMA, BAR, NUMA, drivers, CUDA runtime, container device injection, Kubernetes device plugins, Slurm GRES, and scheduler allocation.

Training Infrastructure

Data parallelism, tensor parallelism, pipeline parallelism, optimizer state, activation memory, gradient synchronization, NCCL collectives, topology, stragglers, checkpoint IO, and failure recovery.

Inference Infrastructure

Model loading, weights vs activations vs KV cache, quantization, batching, PagedAttention, Triton, NIM, TensorRT, vLLM as a comparative tool, metrics, latency/throughput tradeoffs, and capacity planning.

Data Center Reality

Rack power, cooling, airflow, node classes, storage, Ethernet/RoCE vs InfiniBand, DPUs, switch topology, cabling, fabric health, maintenance windows, and operational blast radius.

Lesson Sequence

  1. GPU Baseline Diagnostic: prove what the local lab can see from host, container, and Kubernetes.
  2. GPU Execution Mental Model: CPU vs GPU, SMs, warps, memory hierarchy, and why AI kernels fit the hardware.
  3. Driver To Container Path: kernel driver, user-space libraries, CUDA compatibility, NVIDIA Container Toolkit, and runtime injection.
  4. Kubernetes GPU Plumbing: device plugin vs GPU Operator, allocatable resources, pods, node labels, tolerations, and DCGM exporter.
  5. Memory Is The First Bottleneck: VRAM budget, quantization, KV cache, batch size, and the A2000 as a constraint lab.
  6. NGC And NVIDIA Containers: registry auth, image tags, framework containers, Triton images, and deployment failure modes.
  7. Triton Serving Basics: model repository, backends, dynamic batching, metrics, and a tiny local model.
  8. NIM As Productized Inference: what it abstracts, what it still depends on, and where it fits in AI Enterprise.
  9. Slurm GPU Scheduling: GRES, cgroups, partitions, job requests, fairness, and why HPC scheduling differs from Kubernetes.
  10. Run:ai Concepts: queues, quotas, projects, over-quota, GPU fractions, training vs inference workflows.
  11. MIG, vGPU, Time-Slicing, DRA: isolation and sharing mechanisms, which are hardware-enforced, and what the exam expects.
  12. NCCL And Distributed Training: collectives, all-reduce, topology detection, PCIe/NVLink/IB paths, and failure signatures.
  13. AI Fabric And Storage: RoCE vs InfiniBand, congestion, GPUDirect RDMA, GPUDirect Storage, Magnum IO, checkpoint pressure.
  14. Facilities For AI: power density, cooling, thermal throttling, rack design, maintenance, and capacity planning.
  15. Operations Drill: diagnose a broken GPU workload from symptoms through DCGM, Kubernetes/Slurm, containers, fabric, and storage.

Cloud Rental Triggers

Use cloud only when the real mechanism cannot be exposed locally: MIG profiles, multi-GPU/NVLink, InfiniBand or RoCE fabric behavior, vGPU licensing, large-model memory pressure beyond 6 GB, or hands-on exam-style labs unavailable on the A2000.
