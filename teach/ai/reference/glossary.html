AI Infrastructure Glossary

A living reference for the terms that must become automatic while studying for NCP-AIO and building real AI infrastructure depth.

Curriculum · Lesson 1

Rule: when two terms sound similar, preserve the operational distinction. For example, MIG is hardware partitioning; time-slicing is scheduled sharing; vGPU is mediated virtualization with licensing and a hypervisor boundary.

GPU Hardware

SM
Streaming Multiprocessor. The major execution block inside an NVIDIA GPU; it schedules warps and contains CUDA cores, registers, shared memory, and specialized units.
Warp
A group of 32 threads scheduled together on NVIDIA GPUs. Warp behavior explains many GPU performance and divergence effects.
VRAM
GPU-attached memory used for model weights, activations, KV cache, workspaces, and framework/runtime overhead. On the A2000 this is the tight 6 GB budget.
Memory Bandwidth
The rate at which the GPU can move data to and from VRAM. Many AI kernels are limited by memory movement rather than raw arithmetic.
PCIe
The host-to-device interconnect in the local workstation. It is slower and higher latency than on-package or GPU-to-GPU links such as NVLink.
NVLink
NVIDIA high-bandwidth GPU-to-GPU interconnect used in larger systems. Relevant for distributed training and Fabric Manager topics, but not present on the local A2000 setup.
NVSwitch
A switch fabric that connects multiple GPUs with high bandwidth inside systems such as DGX-class servers.

Software Stack

CUDA
NVIDIA's parallel programming platform and runtime model. Most higher-level AI frameworks ultimately depend on CUDA libraries and driver compatibility.
cuDNN
GPU-accelerated primitives for neural networks, including convolution, attention, matmul, pooling, and normalization.
TensorRT
NVIDIA inference optimization SDK. It builds optimized execution plans using precision choices, fusion, dynamic shapes, and hardware-specific kernels.
Triton
NVIDIA inference server for serving models across multiple backends with HTTP/gRPC, model repositories, dynamic batching, metrics, and production serving features.
NIM
NVIDIA Inference Microservice. A productized model-serving container/API layer for supported models, built on NVIDIA runtime components and distributed through NGC.
NGC
NVIDIA's catalog and registry for containers, models, Helm charts, and enterprise-supported AI software artifacts.
AI Enterprise
NVIDIA's enterprise-supported software suite that packages and supports many AI infrastructure and application-layer components.

Operations

GPU Operator
Kubernetes operator that manages NVIDIA GPU enablement components such as drivers, container runtime integration, device plugin, MIG management, and DCGM exporter.
Device Plugin
Kubernetes integration that advertises GPU resources to the kubelet and makes them allocatable to pods.
DCGM
Data Center GPU Manager. NVIDIA's management and telemetry layer for GPU health, metrics, diagnostics, and operational monitoring.
XID
NVIDIA driver error code family reported for GPU faults. XIDs are essential signals when diagnosing hardware, driver, or workload instability.
ECC
Error-correcting code memory. Correctable and uncorrectable ECC events matter for reliability and node health policy on data-center GPUs.
Fabric Manager
NVIDIA service used on NVSwitch/NVLink systems to initialize and manage the GPU fabric.
Magnum IO
NVIDIA's family of technologies for accelerated IO across networking and storage, including GPUDirect-related data paths and NCCL context.

Scheduling And Sharing

Slurm
HPC workload manager used for batch scheduling, GPU resource requests, partitions, accounting, and topology-aware training jobs.
Run:ai
NVIDIA workload orchestration platform for AI workloads, commonly using Kubernetes with queues, quotas, projects, and GPU sharing policies.
GRES
Generic RESource in Slurm. GPUs are commonly represented as GRES so jobs can request and be constrained to allocated devices.
MIG
Multi-Instance GPU. Hardware-backed partitioning on supported data-center GPUs. Not available on the local RTX A2000.
vGPU
Virtual GPU. A mediated virtualization model involving hypervisors, guest drivers, and NVIDIA licensing; different from MIG and Kubernetes time-slicing.
Time-Slicing
Scheduler-level sharing where multiple workloads take turns on the same physical GPU. It improves access but does not provide MIG-like hardware isolation.
DRA
Kubernetes Dynamic Resource Allocation. A newer model for richer device allocation than the older extended-resource path.

Training And Inference

Data Parallelism
Training strategy where each GPU holds a model replica and processes different data, then synchronizes gradients.
Tensor Parallelism
Strategy that splits individual tensor operations or layers across GPUs, commonly needed when a model layer is too large or too slow for one GPU.
Pipeline Parallelism
Strategy that splits model layers across devices and moves microbatches through stages like an assembly line.
NCCL
NVIDIA Collective Communications Library. Provides optimized collectives such as all-reduce, all-gather, broadcast, and reduce-scatter.
All-Reduce
A collective operation where participants reduce values, such as gradients, and all receive the result. It is central to data-parallel training.
KV Cache
Transformer inference memory used to store attention keys and values for previous tokens. It grows with batch size and sequence length.
Quantization
Using lower-precision representations for weights or activations to reduce memory and bandwidth demand, often trading some quality or complexity.
Batching
Grouping requests or inputs to improve GPU utilization. It often improves throughput while increasing queueing latency.

Networking And Facilities

InfiniBand
Low-latency, high-bandwidth fabric commonly used in AI/HPC clusters, especially for distributed training.
RoCE
RDMA over Converged Ethernet. Provides RDMA semantics over Ethernet and requires careful congestion/loss management.
DPU
Data Processing Unit, such as NVIDIA BlueField. Offloads and isolates networking, storage, security, and infrastructure services.
DOCA
NVIDIA's software framework for programming and operating BlueField DPU services.
Power Density
Power draw per rack or area. AI systems can exceed traditional data-center assumptions and drive cooling and facility design.
Thermal Throttling
Automatic performance reduction when hardware reaches thermal limits. It can look like a mysterious performance regression unless monitored.
