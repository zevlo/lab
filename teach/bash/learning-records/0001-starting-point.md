# Starting point: comfortable with commands, scripts feel like magic

Established 2026-09-10. The user is a DevOps engineer whose work spans CI/CD pipelines, Linux servers, and containers. They run terminal commands comfortably but have not written scripts. Mission: automate their own work and read/fix existing shell code. Budget ~30 min/day on a macOS terminal.

Implications: start at "commands → saved, executable script", not at `cd`/`ls`. Expect the classic self-taught gaps: quoting, word splitting, exit-status thinking. Watch for the fluency illusion — they may recognise syntax without being able to produce it, so prefer production exercises over recognition-only quizzes.
