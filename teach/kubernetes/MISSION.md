# Mission: Kubernetes Fundamentals

## Why
Build real operational competence with Kubernetes for two concrete uses: confidently deploying and operating services at work, and running a personal Kubernetes homelab. The goal is hands-on fluency — not just recognizing concepts, but being able to drive a cluster from a blank terminal.

## Success looks like
- Can deploy, expose, scale, and debug an application on a cluster without looking up basic commands
- Can read a YAML manifest and predict exactly what the cluster will do with it
- Runs a homelab cluster with real workloads (and can recover it when it breaks)
- Can explain to a colleague *why* Kubernetes behaves the way it does (control loops, desired state), not just *what* commands to run

## Constraints
- Intense pace: multiple sessions per week, but each lesson must stay small and self-contained
- Practice happens hands-on against a local cluster (OrbStack on macOS) plus quizzes for retention
- Has Docker/container experience; used minikube on LabEx previously, but all local labs target OrbStack

## Out of scope (for now)
- Certification prep (CKA/CKAD) — may become relevant later, revisit if mission shifts
- Cluster bootstrapping internals (Kubernetes the Hard Way territory) — until fundamentals are solid
- Service meshes, operators, CI/CD pipelines — later layers
