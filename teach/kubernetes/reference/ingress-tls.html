Ingress TLS

Quick reference — certificates, Secrets, and HTTPS at the door.

Where TLS terminates

HopEncrypted?
Client → Ingress controller (Traefik)Yes — TLS terminated here
Ingress controller → Service → PodNo — plaintext inside cluster (by default)

TLS Secret

kubectl create secret tls my-tls \
  --cert=tls.crt --key=tls.key -n homelab

Type kubernetes.io/tls. Required data keys: tls.crt, tls.key. Must live in the same namespace as the Ingress.

Ingress TLS block

spec:
  tls:
  - hosts:
    - hello.k8s.orb.local
    secretName: hello-tls
  rules:
  - host: hello.k8s.orb.local
    http:
      paths: ...

tls.hosts must match rules.host — SNI selects the certificate by hostname.

Local homelab cert (self-signed)

openssl req -x509 -nodes -days 365 -newkey rsa:2048 \
  -keyout tls.key -out tls.crt \
  -subj "/CN=hello.k8s.orb.local" \
  -addext "subjectAltName=DNS:hello.k8s.orb.local"

Browsers and curl warn until you trust the CA or use curl -k. Production: cert-manager + Let's Encrypt (or your CA).
