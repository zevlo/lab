Fundamentals Map

Quick reference — how the 22 lessons stack into one operational picture.

One sentence: You declare desired state in YAML; controllers reconcile reality; you debug by comparing manifest → API objects → pod events → bindings (Service, PVC, Ingress).

The control loop (everything else hangs on this)

YOU write manifest  →  API server stores desired state  →  controller watches
  →  creates/updates objects  →  kubelet runs containers  →  STATUS reflects reality
  →  you read STATUS and fix the manifest

Layers (bottom → top)

1 · Scope & policy

Namespace, context, ResourceQuota, LimitRange — where objects live and what a namespace may consume.

Lessons 0007, 0011 · namespace policies ref

2 · Workloads

Pod (atomic) → Deployment (stateless, rolling updates) · StatefulSet (stable identity, ordered scale, per-pod PVC).

Lessons 0004, 0016 · StatefulSets ref

3 · Configuration & health

ConfigMap / Secret inject env and files. readinessProbe = membership (endpoints). livenessProbe = existence (restart).

Lessons 0005, 0006 · configuration ref

4 · Resources & scale

requests / limits → scheduling & OOM. HPA needs requests + metrics-server for CPU %. Quota caps namespace totals.

Lessons 0009, 0012 · resources ref · HPA ref

5 · Networking

Service (stable VIP → EndpointSlice of pod IPs). Ingress (HTTP host/path → Service port). NetworkPolicy (permit/deny pod traffic — separate from routing).

Lessons 0002, 0003, 0019, 0021 · NetworkPolicy ref

6 · TLS

Manual: TLS Secret + spec.tls.secretName on Ingress (0008). Automated: Issuer → Certificate → Secret → Ingress (0022).

Ingress TLS ref · cert-manager ref

7 · Storage

PVC binds to PV (dynamic via StorageClass). Pending pod + unbound claim → describe PVC first.

Lesson 0015 · storage ref

8 · Authoring & delivery

kubectl apply (declarative). kustomize build / apply -k (layers). helm template (preview) vs helm upgrade --install (release).

Lessons 0010, 0013, 0014 · authoring ref

9 · Operations

Triage funnel: SCOPE → STATUS → EVENTS → LOGS → RELATED. Rollout incidents: rollout status → get rs → failing pod.

Lessons 0017–0020 · troubleshooting ref

10 · Identity & API authz (ops hardening)

ServiceAccount = who the Pod is. Role / RoleBinding = what the API allows. Diagnose with kubectl auth can-i --as=system:serviceaccount:… — not your admin kubeconfig.

Lesson 0024 · RBAC ref

Traffic path (debug inside-out)

curl https://app.example.com/path
  → Ingress (host, path, tls.secretName, backend.service.port)
  → Service (selector → labels, port → targetPort → containerPort)
  → Pod (readiness → EndpointSlice membership)
  → NetworkPolicy (may block even if routing is correct)
