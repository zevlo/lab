Kustomize

Quick reference — base + overlays, no template language.

What it is

Kustomize builds Kubernetes YAML from a base plus environment overlays — patches, name prefixes, image tags, replica counts — without {{ .Values }} templating. Built into kubectl (-k flag). Output is plain manifests you still apply; same control loop as lesson 0010.

Directory layout

app/
├── base/
│   ├── kustomization.yaml    # lists resources
│   ├── deployment.yaml
│   └── service.yaml
└── overlays/
    ├── staging/
    │   ├── kustomization.yaml  # references ../../base + transforms
    │   └── resources-patch.yaml
    └── production/
        └── kustomization.yaml

base/kustomization.yaml

apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
- deployment.yaml
- service.yaml

overlay/kustomization.yaml

apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

namespace: kustomize-lab
namePrefix: stg-

resources:
- ../../base

replicas:
- name: api          # base metadata.name, before prefix
  count: 1

images:
- name: nginx        # image name without tag
  newTag: "1.27"

patches:
- path: resources-patch.yaml

Common transformers

FieldEffect
resourcesYAML files or paths to other kustomization directories
namespaceSet namespace on all resources; creates if missing on apply
namePrefix / nameSuffixPrefix/suffix resource names and references
replicasOverride Deployment/ReplicaSet replica count by base name
imagesRetag (or rename) container images
patchesStrategic-merge or JSON6902 patches; target base names pre-transform
configMapGeneratorBuild ConfigMaps from files/literals; hash suffix on name

Commands

kubectl kustomize overlays/staging          # render to stdout — preview
kubectl apply -k overlays/staging           # build + apply
kubectl diff -k overlays/staging            # diff rendered output vs cluster
kubectl delete -k overlays/staging          # delete what -k would apply

Patch rules

Strategic-merge patches reference the resource's base metadata.name (e.g. api), not the prefixed name (stg-api). Kustomize applies transformers first conceptually, but patch targets use pre-transform identifiers.

Kustomize vs Helm

KustomizeHelm
MechanismOverlays + patches on YAMLGo templates + values.yaml
LogicNone — no loops/conditionals in coreFull templating
Ship modelPlain dirs in gitCharts (packaged tarballs)
End statekubectl apply -khelm install/upgrade
