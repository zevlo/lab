Reference · tmux

Sessions, windows, panes

The hierarchy and the default keys that cover most day-to-day tmux. Prefix is C-b. Detach leaves the session alive.

Hierarchy

session  — persistent; survives C-b d and SSH drops
  └── window — full-screen "tab" inside a session
        └── pane  — split region; one pty / shell each

One tmux server per machine (socket) manages all sessions. A client is your attached terminal. See DESCRIPTION in man tmux.

Shell commands (outside / detached)

CommandDoes
tmux new -s nameCreate session name and attach
tmux lsList sessions (list-sessions)
tmux attach -t nameAttach to existing session
tmux attachAttach to the default / only session

Prefix keys (pareto set)

Press Ctrl-b, release, then the command key. From DEFAULT KEY BINDINGS in man tmux.

KeysDoes
C-b dDetach client
C-b cNew window
C-b n / pNext / previous window
C-b 0…9Select window by index
C-b %Split left / right
C-b "Split top / bottom
C-b oNext pane
C-b ←↑↓→Pane by direction
C-b zZoom pane (toggle)
C-b xKill pane (confirm)
C-b ?List key bindings
Indexing. Stock tmux: windows start at 0. A local base-index 1 only affects machines with that config — assume 0 on bare remotes.
