Copy-mode keys (emacs — stock default)

From man tmux: default mode-keys is emacs unless EDITOR/VISUAL contains vi. Check: tmux show -g mode-keys.

KeysDoes
arrows / PgUp PgDnMove / page in scrollback
C-SpaceBegin selection
M-w (Option-w on Mac)Copy selection → tmux buffer; exit copy-mode
C-gClear selection
This Mac. Option-w fills the tmux paste buffer. It does not update the macOS clipboard / Notes. Portable paste is C-b ]. For OS clipboard, use Ghostty/mouse selection (or later OSC 52 / set-buffer -w — not this lesson’s pareto).
