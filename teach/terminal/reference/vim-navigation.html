Navigation

Stop crawling with hjkl. The commands on this page get you anywhere in a buffer in three keystrokes or fewer.

Char on a line — f F t T + ; ,

The fastest way to land on a specific column. finds and tills, forward and backward.

KeyAction
f{x}Forward to next {x}, cursor ON it
F{x}Backward to previous {x}, cursor ON it
t{x}Forward till next {x}, cursor one BEFORE
T{x}Backward till previous {x}, one AFTER
;Repeat last f/F/t/T in same direction
,Repeat last f/F/t/T in reverse direction
Operators compose with these as motions. dt, deletes to the next comma. cf" changes forward to the next quote. yt; yanks to the next occurrence of the last f target.

Brace matching — %

From any of ( [ { ) ] }, jump to its match. From a non-brace char, jumps to the next brace on the line. Indispensable for JSON, embedded code blocks, and function calls.

%Jump to matching brace
d%Delete from cursor to matching brace (inclusive)
c%Change from cursor to matching brace
v%Visually select from cursor to matching brace
Pair with text objects from the grammar reference: di{ clears a JSON object's contents; da{ removes the object and its braces.

Marks — bookmark a spot

Set a named mark anywhere; jump back to it later. Lowercase marks are per-buffer; uppercase are global across buffers.

KeyAction
m{a-z}Set mark {a} at cursor (buffer-local)
m{A-Z}Set global mark (survives buffer switches)
'{a}Jump to first non-blank on mark {a}'s line
`{a}Jump to exact column of mark {a}
''Jump to line of last jump
``Jump to exact column of last jump

Built-in marks (always available)

`.Position of last change
`^Position of last insert
`[ / `]Start / end of last yanked or changed text
`< / `>Start / end of last visual selection
Devops idiom: editing a long config, set ma on the line you're working on, detour with /search to check a related value, then 'a snaps you back. No mental overhead of "where was I?"

Jump list — the universal back button

Every jump (any motion that moves more than a line) is recorded. Walk back through your trail.

Ctrl-oJump back through the jump list
Ctrl-iJump forward through the jump list
:jumpsShow the jump list

Bonus — quick returns worth memorizing

giReturn to last insert position and enter insert mode — great for resuming edits
gvRe-select the last visual selection
gdJump to local definition of word under cursor
gDJump to global definition of word under cursor
* / #Next / previous occurrence of word under cursor (search — covered in Lesson 0003)
