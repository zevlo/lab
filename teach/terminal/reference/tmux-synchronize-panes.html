synchronize-panes

Type once; every pane in the window gets the keystrokes. Mission tool for parallel multi-host ops. No default key — use the command prompt.

What it does

From man tmux: window option synchronize-panes duplicates input to all other panes in the same window where the option is also on (panes not in a mode).

Commands (stock — no remaps)

HowCommand
tmux promptC-b : then setw synchronize-panes on
tmux promptC-b : then setw synchronize-panes off
toggleC-b : then setw synchronize-panes
from shelltmux setw synchronize-panes on
checktmux show -w synchronize-panes
Scope. Window-local. Other windows in the session are unaffected. Turn it off when the parallel burst is done — leaving it on is how you broadcast a typo to every host.

Typical multi-host shape

# one window, N panes — each already ssh'd to a host
C-b :  setw synchronize-panes on
# type the same triage commands everywhere
C-b :  setw synchronize-panes off
# continue in one pane only

Beyond the pareto

Custom binds (e.g. toggle on C-b S), status-line indicators for sync state, scripting pane labels. Defaults-only mission skips binds.
