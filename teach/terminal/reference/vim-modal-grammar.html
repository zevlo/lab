The vim editing grammar

Operators, motions, and text objects combine into a single sentence. Memorize the parts, compose on the fly — never memorize whole commands.

The four modes

ModeHow you enter itWhat it's for
NormalEsc (the default)Move and operate on text. Where the grammar lives.
Inserti a I A o OType literal characters into the buffer.
Visualv V Ctrl-vSelect a region, then apply an operator to it.
Command-line: / ?Ex commands, search patterns, substitutions.

The grammar

[count]   operator   [count]   motion / text-object e.g. d3w · 2dd · ci" · >ip

A count may sit on either side of the operator; counts multiply. d3w and 3dw are identical. The operator says what to do; the motion or text-object says where.

Motions — where to go

Char & line

h j k lleft / down / up / right
0start of line
^first non-blank char of line
$end of line
f{x} / F{x}next / previous {x} on the line
t{x} / T{x}till next / previous {x} (stops one short)
; / ,repeat / reverse last fFtT

Word

w / bnext / previous start of word
e / genext / previous end of word
W B Esame, but by WORD (whitespace-delimited)

Document

ggfirst line
Glast line (or {n}G for line n)
{ / }previous / next blank line (paragraph bound)
H M Ltop / middle / bottom of viewport
%matching brace / paren / bracket

Text objects — a thing rather than a direction

Text objects replace a motion with a structural unit. Use a for "around" (includes delimiters) and i for "inner" (excludes them).

KeySelects
aw / iwa / inner word
aW / iWa / inner WORD
as / isa / inner sentence
ap / ipa / inner paragraph
a" / i"double-quoted string
a' / i'single-quoted string
a` / i`backtick-quoted string
a) / i) (also b)parenthesized block
a] / i]bracketed block
a} / i} (also B)braced block
at / itaround / inner HTML/XML tag

Idioms — composable patterns

CommandReads as
ciwchange inner word — fastest rename
ci"change contents of a string
ci( / ci{change arguments / block contents
da"delete a string and its quotes
c$ (or C)change to end of line
d0delete to start of line
>ipindent this paragraph
gg=Gre-indent the entire file
gUiwupper-case this word
~ipflip case across a paragraph
dt,delete up to (but not including) the next comma
yss) ... no, that's a pluginSkip plugin-sugar patterns; use vi( + S or operators directly.
Doubled operators act on the current line. dd, cc, yy, >>, == all apply to the whole line. 3dd deletes three lines.
