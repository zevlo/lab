Visual & block mode

When an operator + motion isn't enough — select first, then act. Block mode is the surgical tool for column-shaped edits.

Three visual modes

KeyMode
vChar-wise — selects a range of characters
VLine-wise — always whole lines
Ctrl-vBlock-wise — a rectangular column

Press Esc (or Ctrl-[) to leave any visual mode.

Inside visual mode

oMove cursor to the other end of the selection (useful when you overshoot)
OIn block mode: move cursor to the other corner of the rectangle
gvRe-select the last visual selection (works from normal mode too)

Operators on a selection — the grammar extends

From Lesson 0001, the grammar was operator + motion. Visual mode gives you a second shape: operator + selection. After selecting, apply any operator:

d / xDelete the selection
cChange the selection (delete + insert)
yYank (copy) the selection
> / <Indent / dedent
=Auto-indent (e.g., format JSON)
U / uUppercase / lowercase
~Toggle case of each char

Text objects as visual selectors

Any text object from the grammar reference doubles as a visual selector — prefix with v to "see before you act":

viw / vawInner / around word
vi" / va"Inside / around a quoted string
vi( / va(Inside / around parens
vi{ / va{Inside / around braces
vip / vapInner / around paragraph
Use vi(...) when you want to see the region before operating, or to apply an operator other than c/d/y — e.g., vi(U to uppercase a function's arguments.

Block mode — the surgical column tool

Block-wise visual (Ctrl-v) is vim's most distinctive power tool. The selection is a rectangle — the same columns across multiple lines.

Block insert / append — propagates to every line

Ctrl-v … select … IInsert before the block on every line. Type once; Esc propagates.
Ctrl-v … select … AAppend after the block on every line
Ctrl-v … select … cChange each line's segment; same text on every line after Esc
Ctrl-v … select … r{x}Replace every char in the rectangle with {x}
Ctrl-v … select … x / dDelete the rectangle
Common idiom — comment out a block: Ctrl-v select the first column of the lines, I# <Esc>. Each line gets # prepended. To uncomment: Ctrl-v select the # column, d.

Operating on the last selection — '<,'>

After leaving visual mode, the markers '< and '> point at the start and end of the last selection. Vim auto-fills the range when you press : from visual mode:

:'<,'>s/old/new/gSubstitute within the last selection only
:'<,'>!sortFilter the selected lines through sort
:'<,'>w /tmp/snip.txtWrite just the selection to a file
gvRe-select the last region (normal-mode shortcut)
Use :'<,'>s/.../.../ to scope a substitution when :%s would over-match — e.g., rename a key only inside one YAML stanza.

Beyond the pareto

Ctrl-v + $Block select to varying line ends (each line to its own last char)
:norm {cmd}Repeat normal-mode keystrokes across each line of a selection. Powerful for edits :s can't express.
g Ctrl-gCount words / lines / chars in the selection
! in visualFilter selection through an external command (Vip!sort)
p over a block selectionPaste a register over the rectangle (replaces each line's segment)
