Lesson 0002 · Phase 2 — vim

Audit your speed, then learn to jump

You've got the grammar. Now stop crawling with hjkl and learn the navigation commands fluent operators use to fly.

The audit — measure your current speed honestly

Before any new content, time yourself on a small edit using your old habits. After the lesson, you'll redo it with the new tools and compare.

  1. Open a scratch file: 
    cd /tmp && vim audit.json
  2. Paste in this JSON config (in vim: i, paste, Esc): 
    {
  "service": {
    "name": "api-gateway",
    "version": "2.4.1",
    "endpoints": [
      {"path": "/users", "method": "GET", "handler": "listUsers"},
      {"path": "/orders", "method": "POST", "handler": "createOrder"}
    ],
    "database": {
      "host": "db.internal",
      "port": 5432,
      "pool": {"min": 5, "max": 50, "idleTimeoutMs": 30000}
    }
  }
}
  3. Task: change api-gateway to edge-gateway, and change db.internal to db-blue.internal. Two edits.
  4. Use whatever you'd normally use — arrow keys, search, manual selection. Note your start time and end time. Don't use anything from this lesson yet — it's a baseline.
  5. Write your time down. We'll come back to it after the lesson.

Knowledge 1 — char search on a line: f F t T

To land on a specific character on the current line without counting words:

f{x}forward to next {x}, cursor lands ON it
F{x}backward to previous {x}
t{x}forward till next {x}, cursor stops one BEFORE
T{x}backward till previous {x}
;repeat last f/F/t/T (same direction)
,repeat last f/F/t/T (reverse direction)

These compose with operators as motions. Recall Lesson 0001's grammar: operator + motion. The motion can be a char search.

  • dt, — delete forward to the next comma (keeps the comma)
  • df, — delete forward through the next comma (kills the comma too)
  • cf" — change forward to the next double-quote
  • yt; — yank forward to the next occurrence of whatever you last f'd

Knowledge 2 — brace matching: %

From a brace (( [ { ) ] }), % jumps to its match. From a non-brace char, it jumps to the next brace on the line first, then to its match on the next press.

On the audit file, place your cursor on the { at the start of "pool"'s value. Press % — you land on its matching }. Press % again — back.

As a motion, % composes too:

  • d% — delete from cursor to the matching brace (inclusive)
  • v% — visually select from cursor to the matching brace

This is the devops-killer: trace through nested JSON without scrolling.

Knowledge 3 — marks: bookmark a spot

Sets a named anchor you can return to. Lowercase marks are per-buffer; uppercase are global.

m{a}set mark {a} at cursor
'{a}jump to first non-blank on mark {a}'s line
`{a}jump to the exact column of mark {a}
''jump to the line of the last jump (last 'x or / or G)

The canonical devops idiom: you're editing a long config, set ma on the line you're changing, detour with /something to verify a related value, 'a snaps you straight back. No "where was I?" cognitive cost.

Knowledge 4 — the universal back button: Ctrl-o / Ctrl-i

Every jump (any motion that moves more than a line, including marks, search, G, etc.) is recorded in the jump list. Walk back through your trail:

  • Ctrl-o — jump back through the jump list
  • Ctrl-i — jump forward through the jump list
  • :jumps — see the list

Use this when you forgot to set a mark but need to get back.

Worked examples — read each as a sentence

  • f: — jump to next colon on this line
  • f:; — jump to the second colon (find colon, repeat)
  • dt, — delete forward to the next comma
  • cf" — change forward to the next quote
  • % on a { — jump to its match
  • ma … /log … 'a — bookmark, search, return
  • Ctrl-o — "wait, go back"

Drill — same audit, new tools (~6 min)

  1. Reopen /tmp/audit.json. Reset the file if you saved it: change edge-gateway back to api-gateway and db-blue.internal back to db.internal.
  2. Redo the same two edits, this time only using the new tools. Reveal each answer only after you've tried.

Tasks

  1. Change api-gateway to edge-gateway using f to reach the line and ci" to change the value.
    show answer

    1G (top of file) or gg, then /api-gateway<Enter> to find it. Or jump directly with f" then ; until you're inside the right string. Then ci", type edge-gateway, Esc.

    Notice: ci" from Lesson 0001 still does the heavy lifting. Navigation is what got you to the right string faster.

  2. Change db.internal to db-blue.internal. Use / to find it, then operator + text-object to edit.
    show answer

    /db.internal<Enter> — cursor lands on d. f. — jump forward to the .. i, type -blue, Esc.

    Or: ci" from inside the quotes, type the whole new value, Esc. Either works; f. is faster for a single-word insertion at a known char.

  3. On the { at the start of the "pool" value, press %. Verify you land on its matching }.
    show what to expect

    One keystroke moves you across multiple lines of nested JSON. This is the devops payoff: trace through a config structurally, not by scrolling.

  4. Set mark ma on the "host" line. Search for createOrder with /createOrder. Jump back with 'a.
    show what to expect

    You should land back on the "host" line at first non-blank. Use `a (backtick) to land at the exact column instead.

  5. Bonus: da{ from inside the "pool" block — delete the whole {"min": 5, ...} object. Undo with u. Note the callback to Lesson 0001's text objects.
    show answer

    Cursor anywhere inside the pool object's braces. da{ — delete around {braces. Removes content and the delimiters. u brings it back.

Compare your times

Look at your baseline time versus how long the second pass took. Most comfortable dabblers cut their time by 40–60% on this specific drill. More importantly, the second pass should have felt smoother — less hunt-and-peck, less scrolling.

If it didn't feel smoother, that's the most useful signal you could give the teacher. Where exactly did you reach for the old habit? Note it and bring it to the next session.

Check your understanding

Four short questions. Click an option; feedback is immediate.

Q1Which key repeats the last f/F/t/T in the same direction?

  • ;
  • ,
  • .
  • :

Q2Which key jumps to the matching brace from the cursor?

  • %
  • *
  • #
  • &

Q3Which command sets mark a at the cursor?

  • ma
  • 'a
  • `a
  • "a

Q4Which returns to the line (first non-blank) of mark a?

  • 'a
  • `a
  • ma
  • Ma

Ask the teacher. Did the audit show a measurable speedup? Did % feel like a superpower or did you forget it was there? Did you find yourself reaching for the mouse/arrow keys despite knowing the new tools — and if so, where?

Bring concrete observations to the next session. The teacher uses them to decide whether to push forward or pause and reinforce.
