The vim editing grammar

Operators, counts, and motions combine into one sentence. Learn the sentence and you stop pressing keys one at a time.

Why this matters

As a DevOps engineer you edit configs constantly — sometimes locally, often over a flaky SSH session. The dabbler's habit of pressing x eight times, or arrow-keying into position and hitting i, is what separates slow operators from fluent ones. Vim isn't a bag of shortcuts; it's a tiny grammar. Once you internalize it, your edits become single sentences your fingers type at the speed of thought.

The grammar

In normal mode, most editing commands have this shape:

[count]   operator   [count]   motion / text-object e.g. d3w  ·  2dd  ·  ci"  ·  >ip

Read it as a sentence. d3w is "delete three words". The operator (d) says what; the motion (3w) says where. The count can sit on either side and they multiply: d3w = 3dw = delete three words. You never memorize dw, d2w, d3w as separate commands — you compose them on the fly.

The three building blocks

Operators — what to do

ddelete (also yanks)
cchange — delete, then enter insert
yyank (copy)
p / Pput after / before
> / <indent / dedent
=auto-indent
~toggle case
gu / gUlowercase / uppercase

Motions — where to go

w / b / enext start / prev start / end of word
0 / ^ / $start / first non-blank / end of line
gg / Gtop / bottom of file
f{x} / F{x}next / prev occurrence of {x} on the line
{ / }prev / next blank line

Text objects — a thing, not a direction

Use a for "around" (includes delimiters), i for "inner" (excludes them).

aw / iwa / inner word
ap / ipa / inner paragraph
a" / i"a / inner double-quoted string
a( / i(a / inner parenthesized block
a{ / i{a / inner braced block

Worked examples — read each as a sentence

  • d3w — delete three words forward
  • ciw — change inner word (the fastest rename you'll ever learn)
  • da" — delete a quoted string including the quotes
  • ci( — change everything inside the parens (function args!)
  • >ip — indent the current paragraph
  • c$ (or just C) — change from cursor to end of line
  • gg=G — re-indent the entire file

Drill — one sentence per task, no arrow keys (~6 min)

  1. In your terminal: 
    cd /tmp && vim drill.yaml
  2. Paste in this broken config (in vim: i to insert, paste, Esc): 
    server:
  host = "localhost"
  port = "8080"
  tags = ["prod", "us-east-1", "prod", "primary"]
  timeout = "30"
  3. For each task below, do it with one vim sentence, not by arrow-keying in and editing by hand. Reveal the answer only after you've tried.

Tasks

  1. On localhost, rename it to 0.0.0.0.
    show answer
    ciw then type 0.0.0.0 then Esc. (change inner word.)
  2. On "8080", strip the quotes so it reads 8080.
    show answer
    da" — delete around double-quote. The "around" variant removes the quotes too.
  3. On the first prod in tags, rename to production.
    show answer
    ciw then production then Esc.
  4. Change the timeout value from 30 to 60.
    show answer
    Cursor inside the quotes, then ci" then 60 then Esc.
  5. Indent the entire server: block one shiftwidth to the right.
    show answer
    Cursor anywhere inside the paragraph, then >ip — > indent inner paragraph.
  6. Bonus: re-indent the whole file cleanly.
    show answer
    gg=G — go to top, auto-indent, to bottom. gg and G are motions; = is the operator in the middle.

Save and read it back: :w then :e! if you want to verify against the original. If every task took one sentence, you've already doubled your vim speed.

Check your understanding

Four short questions. Click an option; feedback is immediate.

Q1Which command changes the inner word and enters insert mode?

  • ciw
  • diw
  • yiw
  • >iw

Q2Which operator deletes from the cursor to the end of the line?

  • d$
  • dG
  • d0
  • dd

Q3Which motion moves to the end of the current word?

  • e
  • w
  • b
  • $

Q4How do you indent the current paragraph?

  • >ip
  • <ip
  • =ip
  • dip

Ask the teacher. Where did this break? Did ciw feel like magic rather than understanding? Did >ip refuse to indent the way you expected? Anything at all fuzzy — say so, and the next lesson untangles it.
