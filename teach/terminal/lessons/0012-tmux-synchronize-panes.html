Lesson 0012 · Phase 3 — tmux

Type once, hit every pane

synchronize-panes — the mission unlock for parallel multi-host commands. No default keybind; the command prompt is the stock path.

Why this matters

Success criteria: drive synchronize-panes from muscle memory for multi-host ops. You already split panes (Lesson 0006). This lesson turns those panes into one keyboard when you want the same triage on every host — then turns that off before a typo goes global.

Knowledge — window option, not a prefix chord

From man tmux: synchronize-panes on duplicates input to all other panes in the same window (panes not stuck in a mode). Stock tmux has no default key for this — use the command prompt (C-b :) or a shell tmux setw ….

ActionStock command
Turn onC-b : → setw synchronize-panes on
Turn offC-b : → setw synchronize-panes off
ToggleC-b : → setw synchronize-panes
Checktmux show -w synchronize-panes
Off when done. Sync left on is how you broadcast rm to every pane. Habit: on → burst of commands → off before exploratory typing.
Window scope. Only panes in the current window. Other windows stay independent. Real workflow: one window per “fleet burst,” ssh already established in each pane, then sync.

Drill — three panes, one keyboard

Local is enough (no SSH required). Simulate hosts with labeled shells.

  1. Session with three panes: 
    tmux new -s syncdrill
# C-b %   then C-b "   → three panes
# C-b o to cycle; in each pane run a label:
    Pane A: export PS1='A> '
    Pane B: export PS1='B> '
    Pane C: export PS1='C> '
    show answer

    You should see three different prompts. Sync is still off — typing in one pane must not appear in the others.

  2. Enable sync from the tmux command prompt: 
    C-b :
setw synchronize-panes on
# Enter
    Confirm: 
    tmux show -w synchronize-panes
    show answer

    Should print synchronize-panes on. The : prompt is prefix then colon — same place you would type any tmux command.

  3. With focus in any pane, type: 
    echo hello-from-sync
hostname
    Watch all three panes receive the same keystrokes.
    show answer

    Every pane runs the same lines. Prompts stay A/B/C; output of hostname is whatever this Mac is — the point is identical input, not identical hosts.

  4. Disable sync, then type only in one pane: 
    C-b :
setw synchronize-panes off
    In one pane: echo only-here — the others must stay quiet.
    show answer

    If all three still echo, sync never turned off — re-run tmux show -w synchronize-panes.

  5. Optional: toggle with bare setw synchronize-panes (no on/off) twice and watch tmux show -w synchronize-panes flip.
    show answer

    Toggle is fine once you trust yourself; explicit on/off is safer under incident stress.

Pareto cut. No custom keybind for sync (defaults-only). Status-line sync indicators later if you want. Cheat sheet: synchronize-panes.

Check your understanding

Four short questions. Answers are shuffled on each page load.

Q1How do you open the tmux command prompt?

  • C-b :
  • C-b ;
  • C-b /
  • C-b ?

Q2Stock command to enable sync?

  • setw synchronize-panes on
  • setw synchronize-panes go
  • setw synchronize-panes all
  • setw synchronize-panes yes

Q3Sync duplicates input across…?

  • panes in one window
  • all tmux sessions
  • all Ghostty tabs
  • all bash histories

Q4After a parallel burst you should…?

  • turn synchronize off
  • turn synchronize up
  • kill every pane
  • detach immediately
