Drill — one incident-shaped pass

All in bash. Prefer recalling the pipeline shape before typing.

  1. Seed a log (heredoc is fine — you may copy this block): 
    cat > /tmp/recall.log <<'EOF'
10.0.0.1 GET /ok 200
10.0.0.2 GET /x 500 ERROR
10.0.0.3 GET /x 500 ERROR
10.0.0.2 GET /x 500 ERROR
10.0.0.4 GET /ok 200
EOF
    From memory: rank ERROR client IPs by count (high → low). Reveal only after you try.
    show answer

    grep ERROR /tmp/recall.log | cut -d' ' -f1 | sort | uniq -c | sort -nr — expect 10.0.0.2 with 2, then 10.0.0.3 with 1.

  2. Capture both streams from a command that fails partway: 
    ls /tmp /no-such-recall
    Write listing + error into /tmp/recall-both.txt (correct merge order). Confirm with cat.
    show answer

    ls /tmp /no-such-recall > /tmp/recall-both.txt 2>&1 — not 2>&1 >file.

  3. See and save the same failure with tee:
    show answer

    ls /tmp /no-such-recall 2>&1 | tee /tmp/recall-tee.txt

  4. Ops loop: start a throwaway server, find it, stop it politely. 
    python3 -m http.server 8766 --bind 127.0.0.1 >/tmp/http8766.log 2>&1 &
    From memory: probe with headers, extract status code with cut, pgrep -f the server, kill TERM, verify with kill -0.
    show answer

    curl -si http://127.0.0.1:8766/ | head -1 | cut -d' ' -f2 → 200. PID=$(pgrep -f 'http.server 8766'); kill "$PID"; kill -0 "$PID" 2>/dev/null || echo gone.

  5. DNS from memory: short A lookup for example.com, then the same via @1.1.1.1.
    show answer

    dig example.com +short and dig @1.1.1.1 example.com +short.

  6. Remote-only recall (skip if no Linux SSH tonight): what exact flag set lists listening TCP with process? Run it and grep for :22 if present.
    show answer

    ss -tlnp then ss -tlnp | grep ':22'. Mac local is lsof — not the mission reflex.

Check your understanding

Six interleaved questions. Answers shuffled on each load. No peeking.

Q1Why sort before uniq -c?

  • uniq needs adjacency
  • sort needs adjacency
  • cut needs adjacency
  • tee needs adjacency

Q2Both streams into out.txt?

  • cmd >out.txt 2>&1
  • cmd 2>&1 >out.txt
  • cmd <out.txt 2>&1
  • cmd >out.txt 1>&2

Q3Portable match on full argv?

  • pgrep -f
  • pgrep -a
  • pgrep -l
  • pgrep -n

Q4Status code from HTTP/1.0 200 OK?

  • cut -d' ' -f2
  • cut -d' ' -f1
  • cut -d' ' -f3
  • cut -d' ' -f4

Q5Terse DNS answer only?

  • dig name +short
  • dig name +trace
  • dig name +noall
  • dig name +answer

Q6Listening TCP + process on Linux?

  • ss -tlnp
  • ss -uanp
  • ss -srlp
  • ss -xanp
