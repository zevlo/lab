Lesson 0006 · Phase 3 — tmux

Sessions, windows, panes

One mental model and a handful of default keys. Detach, come back, and the work is still there — the unlock for remote SSH ops on a bare tmux.

Why this matters

Your mission needs three tmux outcomes early: survive an SSH drop, keep several shells organized without tab chaos, and split a window when two views must stay visible. This lesson is only the hierarchy and the keys that get you 80% of daily use. Copy-mode, synchronize-panes, and layouts wait for later.

Knowledge 1 — the hierarchy

From man tmux: a session is a persistent collection of terminals; each session has one or more windows (full-screen tabs); each window may be split into panes (each a separate pty). The status line at the bottom names the session and lists windows.

session  (survives detach / SSH drop)
  └── window  (a "tab" — full screen)
        └── pane   (a split region — one shell)

You talk to tmux with a prefix, then a command key. Default prefix is Ctrl-b (written C-b). Press prefix, release, then the command key — not all three at once.

Knowledge 2 — outside tmux (shell commands)

These run in bash before you are attached. Aliases: ls = list-sessions, attach = attach-session, new = new-session.

CommandDoes
tmux new -s opsCreate and attach a session named ops
tmux lsList sessions on this machine's tmux server
tmux attach -t opsAttach to session ops (must already exist)
tmux attachAttach to the most recent / only session
Detach ≠ kill. C-b d leaves the session running. Closing the Ghostty window without detaching can also leave it running. tmux ls is how you find orphans. Destroying a session is a different, intentional act — not in this lesson's pareto set.

Knowledge 3 — inside tmux (default keys only)

All chords below are C-b then the key. Sourced from the DEFAULT KEY BINDINGS section of man tmux.

KeysDoes
C-b dDetach this client — session keeps running
C-b cCreate a new window
C-b n / C-b pNext / previous window
C-b 0…9Select window by index
C-b %Split pane left / right
C-b "Split pane top / bottom
C-b oCycle to the next pane
C-b ←↑↓→Move to the pane in that direction
C-b zZoom pane full-window (toggle)
C-b xKill the current pane (confirms)
C-b ?List all key bindings
Window numbers on remotes. Stock tmux indexes windows from 0. Your local ~/.tmux.conf sets base-index 1. On a bare SSH host, C-b 0 is the first window — train that habit for strangers' machines.

Drill — one session you can abandon and reclaim

Do this in Ghostty. If you already have a tmux client attached, detach first (C-b d) so the shell commands below run outside tmux.

  1. Create a named session and confirm the status line shows the name: 
    tmux new -s drill
    show answer

    Status line bottom-left should include drill. You are attached: one window, one pane.

  2. Split left/right, then top/bottom in the active pane, so you have three panes. Cycle with C-b o until each pane has run hostname once.
    show answer

    C-b % then C-b " (order flexible). C-b o cycles focus. Arrow keys after prefix also move by direction — use whichever is faster.

  3. Zoom the pane where your cursor is (C-b z), read a long man tmux page if you want, then un-zoom with C-b z again.
    show answer

    Zoom is the high-leverage pane trick: temporarily fullscreen without destroying the layout. Same key toggles off.

  4. Create a second window (C-b c). In it, run echo window-two. Flip with C-b n / C-b p (or the window number).
    show answer

    Status line should show two window entries. Numbers depend on base-index — locally likely 1 and 2; on stock remotes 0 and 1.

  5. Detach (C-b d). From bash: 
    tmux ls
tmux attach -t drill
    Confirm both windows and your pane layout are intact.
    show answer

    tmux ls should list drill: with a window count. After attach, you are back where you left off — this is the SSH-drop survival story, practiced locally.

Pareto cut (not this lesson). Copy-mode (C-b [), paste buffer (C-b ]), synchronize-panes, preset layouts, renaming, and killing sessions/windows are deferred. Need a binding you forgot? C-b ? is the escape hatch on any stock tmux.

Check your understanding

Four short questions. Answers are shuffled on each page load.

Q1What does C-b d do?

  • detach this client
  • destroy the session
  • delete every window
  • disable the prefix

Q2Which shell command lists sessions?

  • tmux ls
  • tmux ps
  • tmux df
  • tmux id

Q3Default keys to split left/right?

  • C-b %
  • C-b "
  • C-b x
  • C-b z

Q4Largest unit that survives detach?

  • session
  • window
  • pane
  • prefix

Ask the teacher. After the drill: did detach → tmux ls → attach feel boring (good — boring is fluency), or did you lose a layout / hit a second session by mistake? On window numbers: did your local base-index 1 trip you when you reached for C-b 0?

Bring concrete observations. The teacher uses them to choose the next slice of Phase 3: copy-mode on stock defaults (scrollback + yank into the tmux buffer), multi-session habits (C-b s, named sessions per host), or synchronize-panes for parallel multi-host ops.
