# Teaching Notes

- The learner's goal is to build practical skills for a cloud or DevOps role.
- The learner has used the AWS console for a few simple tasks.
- Use simple words, short sentences, active voice, and direct address.
- Follow the Google developer documentation style guide.
- Keep each lesson focused on one tangible win.
- Use retrieval practice and automatic feedback.
- Connect all services through one small production-style application.
- Follow this order: VPC, EC2, S3, IAM, RDS, Route 53, CloudWatch, ECS, and EKS.
- Prefer cost-free exercises. Explain costs and cleanup before any live AWS lab.
