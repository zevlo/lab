Reference · AWS DevOps

Glossary

The canonical language for this workspace. Terms are admitted when you can use them — this baseline rests on your SAA-C03 pass; operational notes deepen lesson by lesson.

When several names exist for one concept, the bolded term is the one this workspace uses. Avoid lists the aliases to retire. Each term links to the AWS docs entry — the ground truth.

Foundations

Region
A geographic cluster of AWS data centres, e.g. eu-west-1. Most resources are scoped to exactly one region.
docs: regions & AZs
Availability Zone (AZ)
One or more isolated data centres inside a Region with independent power and networking. The unit of high-availability: spread across AZs so one failing doesn't take you down.
Avoid: "data centre" used loosely
AWS account
The root container for resources, billing, and identity. Root user credentials should be locked away (MFA, no daily use).
docs: root user

Network (the VPC)

VPC
Your private, logically isolated network in one region. Everything you deploy lives inside one.
docs: VPC
Subnet
A slice of the VPC's IP range inside a single AZ. Public subnets route to the internet; private subnets don't.
Route table
The rules that decide where a subnet's traffic goes. 0.0.0.0/0 → igw is the signature of a public subnet.
Internet gateway (IGW)
The VPC-level door to the public internet. Necessary but not sufficient — a subnet also needs a route to it.
NAT gateway
Managed appliance in a public subnet that lets private-subnet resources make outbound connections without being reachable inbound.
Avoid: "NAT instance" (that's the self-managed ancestor)
Security group (SG)
Stateful firewall attached to a thing (ENI, instance, task). Allow rules only, and rules may reference other security groups — the key compositional trick.
Avoid: "firewall policy" (that's the NACL's vibe)
docs: security groups
NACL
Stateless subnet-level firewall with numbered, ordered rules — including denies. The blunt instrument to the SG's scalpel.
Tutorials Dojo: SG vs NACL
VPC endpoint
A private path from a VPC to an AWS service without crossing the internet. Gateway endpoints: S3, DynamoDB; interface endpoints: most else.
Application Load Balancer (ALB)
Layer-7 load balancer for HTTP/S: routes by path or host to targets (EC2, IP, Lambda), terminates TLS, runs health checks.
docs: ALB

Compute

EC2
A resizable virtual machine — the raw unit of compute in AWS.
Avoid: "server" (blurs who operates what)
AMI
The bootable disk image + metadata template an EC2 instance starts from.
ECS
AWS's first-party container orchestrator: clusters, services, task definitions. Deepest AWS integration, simplest operations.
EKS
Managed Kubernetes control plane — the full k8s API and ecosystem, at the cost of more moving parts.
Avoid: "ECS but better" (different trade-offs, not strictly better)
Fargate
Serverless container runtime — an ECS/EKS launch type where AWS runs each task; you never touch a node.
ECR
AWS's private Docker image registry. Images live here; ECS/EKS pull from here.
Tutorials Dojo: EKS vs ECS

Storage & Database

S3
Durable object storage (eleven nines): buckets hold objects addressed by key. Durability across AZs by default.
Avoid: "drive", "folder" — objects have keys, not paths
EBS
Network-attached block volume for exactly one EC2 at a time. Snapshots of it land in S3.
RDS
Managed relational database (PostgreSQL, MySQL, …). Multi-AZ keeps a standby in a second AZ for failover — an availability feature, not a performance one.
Avoid: conflating RDS with Aurora — Aurora is a separate, AWS-built engine
docs: RDS

DNS & Edge

Route 53
AWS's DNS service plus domain registration and health-checked routing policies (failover, latency, geolocation). Named after port 53, the DNS port.
Hosted zone
The container of DNS records for one domain — an A/AAAA/CNAME/alias set, often aliasing straight at an ALB.
docs: Route 53

Identity & Observability

IAM user
A long-lived identity with permanent credentials. For humans this is an anti-pattern — SSO/federation is the modern default.
IAM role
An identity with temporary credentials that anything — human, EC2 instance, ECS task — can assume. The DevOps default for granting permissions.
Avoid: putting access keys on disk when a role exists
IAM policy
JSON document of Allow/Deny statements over actions, resources, and conditions.
Least privilege
Grant only what a workload needs — the posture you defend in every interview.
docs: IAM best practices
CloudWatch
Metrics, logs, and alarms for nearly everything: namespaces hold metrics, metrics have dimensions, alarms watch thresholds and notify.
CloudTrail
The audit record of API calls — who did what. Pairs with CloudWatch: actions vs. measurements.
Avoid: mixing up CloudTrail (audit) and CloudWatch (telemetry)
Tutorials Dojo: CloudTrail vs CloudWatch
