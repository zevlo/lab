From request to running workload

Use this map to decide which service owns a task. The course adds one service at a time until you can operate the whole system.

One simplified request path
Name Route 53

Turns a domain name into a destination.

Network VPC

Controls network placement and traffic paths.

Compute EC2 · ECS · EKS

Runs the application code.

Data S3 · RDS

Stores objects or relational data.

IAM controls who can do what.
CloudWatch reports what is happening.
