# AWS DevOps Resources

Curated 2026-09-01. Entries verified this session unless noted.

## Knowledge

- [AWS Documentation](https://docs.aws.amazon.com/)
  Canonical reference for every service: exact behavior, limits, CLI syntax. Ground truth — when any lesson conflicts with it, docs win.
- [AWS Well-Architected Framework](https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html)
  AWS's six-pillar architecture doctrine (operational excellence, security, reliability, performance efficiency, cost optimization, sustainability). Use for: the vocabulary of architecture reviews and interviews. Hub: [aws.amazon.com/architecture/well-architected](https://aws.amazon.com/architecture/well-architected/)
- [Well-Architected DevOps Guidance](https://docs.aws.amazon.com/wellarchitected/latest/devops-guidance/devops-guidance.html)
  AWS's own definition of what a DevOps engineer should care about. Use for: framing the whole mission; interview language.
- [Well-Architected Labs](https://www.wellarchitectedlabs.com/)
  Official hands-on labs. Use for: guided practice beyond our lessons.
- [Amazon EKS Workshop](https://www.eksworkshop.com/)
  Official, self-paced, modular (fundamentals, observability, security, networking, automation). New "EKS Essentials" fast paths powered by EKS Auto Mode. Use for: the EKS chapter.
- [Amazon ECS Workshop](https://ecsworkshop.com/)
  Official guided workshop deploying a real app on Fargate. Site is JS-rendered — use a browser. Use for: the ECS chapter.
- [Tutorials Dojo — AWS Cheat Sheets](https://tutorialsdojo.com/links-to-all-aws-cheat-sheets/)
  Dense, well-edited per-service summaries plus sharp comparison sheets (EKS vs ECS, Security Group vs NACL, S3 tiers, ALB vs NLB). Use for: rapid review and pre-interview refresh.
- [AWS Free Tier](https://aws.amazon.com/free/)
  What is actually free (750 t2.micro/t3.micro hours/month, S3/EBS/RDS allowances). Use for: keeping the personal account near $0.
- [Adrian Cantrill — courses](https://learn.cantrill.io/) (paid, one-time purchase)
  Deep, demo-heavy video courses with lifetime access; his [DevOps Engineer Professional (DOP-C02)](https://learn.cantrill.io/p/aws-certified-devops-engineer-professional) course is the natural option if a next cert ever becomes needed. Use for: video learning when a topic won't click from docs. He runs a Discord community too.

## Wisdom (Communities)

- [AWS re:Post](https://repost.aws/)
  Official Q&A community with active AWS support engineers, a Knowledge Center, and ranked experts. Use for: real troubleshooting answers; once confident, answering others' questions is excellent interview prep.
