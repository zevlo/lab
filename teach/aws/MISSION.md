# Mission: Practical AWS for Cloud and DevOps Work

## Why
Build the practical AWS skills needed for a cloud or DevOps role. Learn to deploy, secure, observe, and troubleshoot a small production-style system instead of memorizing service definitions.

## Success looks like
- Explain how VPC, EC2, S3, IAM, RDS, Route 53, CloudWatch, ECS, and EKS fit together.
- Build a secure network and run a small application inside it.
- Store application data with the right compute, object storage, and relational database services.
- Give workloads only the permissions they need.
- Publish, monitor, and troubleshoot the application.
- Deploy a containerized version with ECS and then EKS, and explain when to choose each.

## Constraints
- The learner has used the AWS console for a few simple tasks.
- Teach the services in the requested order: VPC, EC2, S3, IAM, RDS, Route 53, CloudWatch, ECS, and EKS.
- Use short lessons, simple words, active voice, and one main idea per sentence.
- Prefer cost-free exercises. Warn about charges and include cleanup steps before creating paid resources.

## Out of scope
- Certification-specific memorization.
- Advanced enterprise and multi-account design before the core path is complete.
- AWS services that do not directly support the current lesson or mission.
