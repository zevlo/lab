Lesson 01 · Amazon VPC

What makes a subnet public?

Learn one rule that resolves many AWS networking questions: a public subnet has a route to an internet gateway.

Tangible win

By the end, you can inspect an IPv4 route table and decide whether its subnet is public.

Build the mental model

A VPC is your network boundary in one AWS Region. A subnet is an IP address range in one Availability Zone. AWS defines both here.

VPC

A regional network boundary that you define.

Subnet

One IP address range inside one Availability Zone.

Route table

A set of destination-and-target rules for network traffic.

Internet gateway

A VPC component that provides a path to and from the internet.

Internet Any IPv4 destination outside the VPC
↔
Internet gateway Attached to the VPC
↔
Public subnet 0.0.0.0/0 → igw

The subnet's associated route table creates this path.

Read one route table

Destination Target Meaning
10.0.0.0/16 local Keep VPC traffic inside the VPC.
0.0.0.0/0 igw-1234 Send other IPv4 traffic to the internet gateway.

The second route points to an internet gateway. Therefore, a subnet associated with this table is public. AWS shows the same route pattern.

Important distinction

A public subnet does not make every resource public.

An EC2 instance needs at least these items for direct inbound IPv4 access:

  1. A public IPv4 address.
  2. A route through the internet gateway.
  3. A security group rule that allows the requested traffic.

Other controls can still block traffic. For now, remember: public subnet describes a route, not an open door.
