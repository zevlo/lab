Cgroups & Limits

What each Docker limit flag does — and what happens when a container hits it.

01The model in one line

A cgroup is a group of processes the kernel measures and caps. Docker puts each container's processes in one cgroup. Your docker run flags become kernel caps. Namespaces hide the world (Lesson 0003); cgroups cap the damage.

02The flags

flagcapsat the cap, the kernel…
--memory=256mRAMkills the process — OOM killer, exit 137
--cpus=1.5CPUthrottles — the process runs slower, never dies
--pids-limit=100process countblocks new processes ("can't fork")
--memory-swap=256mRAM + swapsame as memory when swap is off — set equal to --memory to disable swap
Memory kills. CPU slows. This pair answers most "why did my container die / why is it slow" questions before you open a single log.

04Where the caps live

Cgroups expose themselves as files under /sys/fs/cgroup (cgroup v2). Docker writes your flags there. The kernel enforces the files.

docker run --rm --memory=100m busybox cat /sys/fs/cgroup/memory.max
# 104857600            ← 100 MB in bytes
docker run --rm --cpus=1.5 busybox cat /sys/fs/cgroup/cpu.max
# 150000 100000        ← quota 150 ms per 100 ms period = 1.5 cores
docker run --rm busybox cat /sys/fs/cgroup/memory.current
# usage right now, in bytes

05Rules worth taping to the wall

  • Always set --memory in production. An uncapped container can starve every neighbor on the host.
  • Check OOMKilled before blaming the app. Exit 137 with OOMKilled: true is a cap problem, not a crash.
  • Disable swap deliberately: set --memory-swap equal to --memory. Otherwise the kernel will swap instead of killing, and everything just gets slow.
  • --pids-limit is cheap insurance. It stops a runaway fork loop from eating the host's process table.
  • A CPU cap never kills. If a capped container died, look at memory.
  • The main process is PID 1, and PID 1 ignores unhandled signals. docker stop waits its 10-second grace, then SIGKILLs. docker kill SIGKILLs at once. Use --init to get a signal-forwarding PID 1 for programs that need it.
