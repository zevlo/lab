## Plain language (ISO 24495-1:2023)
Every lesson and reference page follows the four principles. Canonical entry: <https://www.iso.org/standard/78907.html>.

- Relevant. The first lines say what the reader will be able to do, and why that task shows up in this job.
- Findable. Headings are questions or tasks. The path page says where the reader is. Lessons link to the path and to earlier lessons.
- Understandable. Short sentences. Familiar words. Define a term at first use, then use that same word. One idea in each paragraph. Active voice.
- Usable. Steps the reader can do on the page. A check with immediate feedback. One primary source to read next. A reminder to ask the teacher.

Quiz options for a single question use the same number of words, and the same number of characters when that can be done without bending the sentence.
