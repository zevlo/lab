Windows and PowerShell Cheat Sheet

Companion to Lesson 0007. Sources: What is PowerShell?, about_Execution_Policies, about_Logging_Windows, AD DS overview, DISA STIG library. Control text: SP 800-53 via CPRT.

What is what

TermDefinition
PowerShellA command-line shell, a scripting language, and a configuration management framework. Cross-platform.
CmdletOne PowerShell command, named Verb-Noun. Get-Service, Set-ItemProperty.
PipelineChains commands and carries .NET objects. Text parsing has no job.
ElevationRunning a shell as Administrator. The sudo shape.
AD DSActive Directory Domain Services. The directory storing user and computer accounts; one logon works network-wide.
Domain joinRegisters a computer account in the domain. Identity flows from AD DS after that.
GPOGroup Policy Object. A declared set of Windows settings, stored in the domain, pushed to member computers.
gpupdateForces a policy refresh on demand.
DSCDesired State Configuration. Configuration as code: enforces settings, reports drift.
Event LogWindows logging sink. Read with Get-WinEvent.
Module loggingRecords pipeline execution for named modules.
Script block loggingRecords script block content as processed. Event ID 4104, Operational channel. Enabled by GPO.
Protected Event LoggingEncrypts sensitive log content with a public key; decrypted at the central collector.
Execution policyGates which scripts run. Defense in depth: prevents accidents, and a user can bypass it. Settable by GPO.
AllowlistingApplication control (CM-7). Decides what code runs at all. Strongest, heaviest to operate.
SCCDISA's SCAP Compliance Checker. Evaluates Windows STIG content; the oscap role on Windows.

Interview traps

If you hearThe truth
“Execution policy stops malware”It is defense in depth; a user bypasses it easily. It prevents accidents.
“PowerShell pipes text”The pipeline carries .NET objects. No parsing needed.
“4104 is a logon event”4104 is script block logging. 4624 is a logon.
“We harden Windows by hand”GPO carries the baseline domain-wide. Hand edits drift.
“PowerShell 7 replaces 5.1”7 installs beside the built-in 5.1. Know which one runs your script.

Interview one-liners

PowerShell is a shell, a scripting language, and a configuration framework, and its pipeline carries objects end to end.
AD DS holds the identities; GPO carries the settings; one logon works network-wide.
Script block logging writes Event 4104. The audit trail sees the script content, interactive or automated.
Execution policy prevents accidents. Allowlisting and logging carry the real defense.
