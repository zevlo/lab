VMware vSphere Cheat Sheet

Companion to Lesson 0008. Definition sources: Wikipedia: VMware vSphere, Wikipedia: vCenter (convenience; Broadcom docs are bot-walled, browse techdocs.broadcom.com for the authoritative text). STIG layers: cyber.mil/stigs.

What is what

TermDefinition
vSphereVMware's virtualization platform. The suite name.
ESXiThe bare-metal hypervisor, one per physical host.
vCenter (VCSA)The centralized management utility: VMs, multiple ESXi hosts, all dependent components, one location.
ClusterA group of ESXi hosts sharing features: HA, DRS, shared storage.
vMotionMoves a running VM between hosts. Memory streams, changed blocks re-send, a final brief freeze switches over. Needs vCenter.
Storage vMotionMoves virtual disks between datastores, live, mirroring in sync until cutover.
HAHigh Availability. Restarts VMs on surviving hosts after a host fails. Reaction.
DRSDistributed Resource Scheduler. Rebalances load by scheduling vMotion. Prevention. No built-in Proxmox twin.
DatastoreThe storage layer hosts share: VMFS on a SAN or NFS from a filer.
TemplateA VM frozen into a golden image. Clones start from it.
Lockdown modeCloses direct host management. vCenter becomes the single door.
OVF / OVAThe packaging format for exporting a VM and its configuration.

Interview traps

If you hearThe truth
“vSphere and ESXi are the same thing”vSphere is the suite; ESXi is the hypervisor; vCenter is the management plane.
“HA and DRS do the same job”HA reacts to failure. DRS rebalances before it.
“vMotion moves storage”vMotion moves a running VM between hosts. Storage vMotion moves disks.
“We hand-build each prod VM”Clones come from one hardened template. Build once.
“Proxmox has no equivalent”Live migration maps to vMotion. DRS is the honest exception.

Interview one-liners

vSphere is the suite: ESXi is the hypervisor on each host, vCenter is the management plane above them.
vMotion moves a running VM between hosts; Storage vMotion moves its disks between datastores. Both need vCenter.
HA restarts VMs after a host fails. DRS rebalances load before anything starves. Reaction and prevention.
A template is an artifact: hardened once, cloned everywhere, checksum verified at promotion. Build once, applied to VMs.
