Vault Cheat Sheet

Companion to Lesson 0005. Sources: What is Vault?, Seal/Unseal, Lease, Renew, and Revoke, Policies, Run Vault on Kubernetes. Control text: SP 800-53 via CPRT.

What is what

TermDefinition
SecretSensitive information an attacker needs and an application uses: password, API key, encryption key, certificate.
VaultHashiCorp's server for secrets: stores them, generates credentials on demand, performs encryption, audits every request.
Auth methodVerifies identity by delegating to a directory or platform: Kubernetes, LDAP, AppRole. Vault keeps no copy.
TokenWhat authentication returns. Carries policies. Has a lifetime.
PolicyHCL granting capabilities on paths. Deny by default. Explicit deny beats any wider grant.
Secrets engineA module mounted at a path. KV stores static secrets; database issues dynamic ones; transit encrypts as a service.
Static secretHuman-written, versioned, no expiry. The KV engine issues no leases.
Dynamic secretGenerated per request, per caller. Always carries a lease.
Lease / TTLMetadata with a time to live. Vault promises validity for the TTL, then auto-revokes.
Sealed / unsealedSealed: storage reachable, nothing decryptable. Unseal opens the barrier.
Root keyProtects the encryption key that protects the data. Itself protected by the unseal key.
Shamir sharesSplits of the unseal key. A threshold (e.g. 3 of 5) reconstructs it. Presented in any order.
Audit deviceWrites the log of every request, granted or denied. Enabled before other setup.

One request

#StepWhat happens
1AuthenticateClient proves identity to an auth method
2TokenVault issues a token carrying policies
3RequestClient reads or writes a path
4AuditEvery request logged, granted or denied

Policy, minimum working example

path "secret/data/payments/*" {
  capabilities = ["read"]
}
path "secret/data/payments/admin" {
  capabilities = ["deny"]
}

Capabilities: create, read, update, delete, list, sudo, deny. Deny always wins. Policies attach at token creation; contents apply in real time.

Seal / unseal

FactDetail
Key chainencryption key → protected by root key → protected by unseal key
Initvault operator init mints shares plus one root token, once
UnsealThreshold of shares, any order, any machines
Reseal triggersRestart, manual seal, unrecoverable storage error
Auto-unsealDelegates to HSM or cloud KMS; recovery keys replace shares
Classified angleShares split across cleared roles = two-person rule. No one unseals alone.

Vault on Kubernetes

IntegrationMechanism
Agent InjectorWebhook injects an agent; authenticates with the service account; writes secrets to a mounted file
Secrets Store CSICSI driver mounts secrets as a volume at pod start
Vault Secrets OperatorController syncs Vault secrets into native Kubernetes Secrets

Kubernetes Secret: base64 in etcd — encoding, not encryption. No lease, no per-path policy, no read audit. Vault adds all three.

Vault at the boundary

QuestionAnswer
Does a Vault cluster span the boundary?No. Each side runs its own.
Do secrets cross the CDS?No. Artifacts cross. Secrets are fetched on their own side, by workload identity.
What does the low-side Vault hold?Dev and test secrets. High-side Vault holds prod.

Interview traps

If you hearThe truth
“Vault is a password box”It also issues short-lived credentials, encrypts as a service, and audits everything.
“We use the root token daily”Root is revoked after setup. Policies do the work.
“KV secrets expire”Only dynamic secrets carry leases. KV has none.
“Kubernetes Secrets are fine”Base64 is encoding. No TTL, no policy, no audit.
“One admin holds the unseal key”Shamir splits it. Threshold of holders. Two-person rule.

Interview one-liners

Workloads authenticate by identity — service account, LDAP, AppRole — and get a token scoped by a deny-by-default policy. No shared passwords.
Dynamic secrets carry leases: generated on demand, valid for the TTL, revoked the moment we say so. A leak expires instead of haunting us.
Vault starts sealed; a threshold of Shamir shares unseals it. On the high side, no single cleared person can unseal it alone.
Each side of the boundary runs its own Vault. Artifacts cross the CDS; secrets never do.
