Rocky STIG Lab Runbook

Condensed commands for Lesson 0003. No prose — just the moves. Sources: Red Hat hardening guide, ComplianceAsCode, rockylinux.org.

Setup

sudo dnf install -y openscap-scanner scap-security-guide
ls /usr/share/xml/scap/ssg/content/
oscap info /usr/share/xml/scap/ssg/content/ssg-rocky9-ds.xml | grep -i stig

Scan (baseline or after)

sudo oscap xccdf eval \
  --profile xccdf_org.ssgproject.content_profile_stig \
  --results /tmp/results-before|after.xml \
  --report /tmp/report-before|after.html \
  /usr/share/xml/scap/ssg/content/ssg-rocky9-ds.xml | tail -4

# fetch the report from the Mac
scp user@vm-ip:/tmp/report-before.html . && open report-before.html

Fixes applied in the lab

# banner (AC-8 via CCI-000048)
sudo tee /etc/issue <<'EOF'
Authorized use only. All activity may be monitored and recorded.
EOF
printf 'Banner /etc/issue\n' | sudo tee /etc/ssh/sshd_config.d/99-stig-banner.conf

# root login
printf 'PermitRootLogin no\n' | sudo tee /etc/ssh/sshd_config.d/99-stig-rootlogin.conf

# validate BEFORE reload — always
sudo sshd -t && sudo systemctl reload sshd

# patching (SI-2)
sudo dnf update -y && sudo reboot
Safety, in order: 1) prove a second login works before touching sshd. 2) sshd -t before every reload. 3) snapshot before --remediate.

Automatic remediation (stretch)

# Proxmox snapshot FIRST, then:
sudo oscap xccdf eval --remediate \
  --profile xccdf_org.ssgproject.content_profile_stig \
  --results /tmp/results-rem.xml \
  --report /tmp/report-rem.html \
  /usr/share/xml/scap/ssg/content/ssg-rocky9-ds.xml | tail -4
