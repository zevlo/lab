# Mission: DevSec Engineering for Classified Environments

## Why
Land a Lockheed Martin Dev Sec Engineering (E2) role supporting classified infrastructure. Two postings, one identical requirements list. Interviews within weeks; job performance within months.

## Success looks like
- Walk through the RMF seven steps unaided. Name the key artifacts (SysSP, SAP, SAR, POA&M). Explain where a DevSecOps engineer plugs in.
- Explain what a STIG is. Read one STIG requirement. Run an OpenSCAP scan against a Rocky Linux VM in the Proxmox homelab.
- Describe SDLC promotion across classified boundaries (dev → test → prod) and secrets management with Vault.
- Answer an interview question on every bullet in the postings, using correct terminology.

## Constraints
- Timeline: interviewing within weeks. Fluency first. Hands-on labs second. Spaced retention work after interviews.
- Labs: Mac with OrbStack; Proxmox homelab; AWS account; Kubernetes homelab.
- Clearance: inactive Secret, within the 2-year reinstatement threshold.
- Language: all lessons use ISO 24495-1 controlled natural language. One term carries one meaning. Definitions come before first use. Short declarative sentences. No synonyms.
- Prior-knowledge floor: Linux basics, Terraform, GitHub Actions, Docker, Kubernetes, Bash, Python. Never re-teach these.

## Out of scope
- Kubernetes internals and advanced Terraform patterns (already fluent).
- Non-DoD compliance frameworks (SOC 2, HIPAA, PCI).
- Algorithmic/coding interview preparation.
