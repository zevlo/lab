Acronyms

CompTIA Security+ SY0-701 · The exam writes these without expansion and expects you to know them cold · Grows every lesson

Starter set — know these before Lesson 0002

AcronymPlain meaning
AAAAuthentication, Authorization, Accounting — prove who you are, get only the access you should have, and have the actions recorded (Domain 1)
AUPAcceptable Use Policy — the rules for how you may use company systems (a directive control)
CCTVClosed-circuit television — video cameras feeding a private monitor (a physical detective control)
CIAConfidentiality, Integrity, Availability — the three goals of security, called the CIA triad (Domain 1)
DoD 8140The US Department of Defense directive that maps work roles to required certifications — the reason this exam matters for the mission
HVACHeating, ventilation, and air conditioning — an environmental control for server rooms
IaCInfrastructure as Code — defining infrastructure in files a machine can apply (Domain 3; familiar from DevOps)
IDSIntrusion Detection System — watches traffic and raises an alert (a technical detective control)
IPSIntrusion Prevention System — watches traffic and blocks the attack itself (a technical preventive control)
MFAMultifactor authentication — proving identity with two or more different kinds of evidence
PBQPerformance-based question — an exam question you answer by doing, not choosing
VPNVirtual Private Network — an encrypted tunnel across an untrusted network
