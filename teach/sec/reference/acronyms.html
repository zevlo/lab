Acronyms

CompTIA Security+ SY0-701 · The exam writes these without expansion and expects you to know them cold · Grows every lesson

Starter set — covered through Lesson 0008

AcronymPlain meaning
AAAAuthentication, Authorization, Accounting — prove who you are, get only the access you should have, and have the actions recorded (Domain 1)
AESAdvanced Encryption Standard — the symmetric algorithm used for fast bulk encryption (Lesson 0004)
APTAdvanced Persistent Threat — a patient, well-funded actor pattern (usually nation-state) maintaining stealthy access for months (Lesson 0008)
ATOAuthorization to Operate — formal permission for a system to run; in DoD environments, an unauthorized change can void it (Lesson 0006)
AUPAcceptable Use Policy — the rules for how you may use company systems (a directive control)
CACertificate Authority — the trusted issuer that signs certificates (Lesson 0005)
CABChange Advisory Board — the cross-team group that reviews and approves significant changes (Lesson 0006)
CCTVClosed-circuit television — video cameras feeding a private monitor (a physical detective control)
C2Command and control — the channel an attacker uses to remote-control compromised machines (Domain 2)
CIAConfidentiality, Integrity, Availability — the three goals of security, called the CIA triad (Domain 1)
CRLCertificate Revocation List — the CA's published list of revoked certificate serial numbers (Lesson 0005)
CSRCertificate Signing Request — the application sent to a CA for a signed certificate (Lesson 0005)
DNSDomain Name System — translates names to addresses; sinkholed to disrupt malware callbacks (Lesson 0003, Domain 2)
DoD 8140The US Department of Defense directive that maps work roles to required certifications — the reason this exam matters for the mission
HVACHeating, ventilation, and air conditioning — an environmental control for server rooms
IaCInfrastructure as Code — defining infrastructure in files a machine can apply (Domain 3; familiar from DevOps)
IDSIntrusion Detection System — watches traffic and raises an alert (a technical detective control)
IPSIntrusion Prevention System — watches traffic and blocks the attack itself (a technical preventive control)
MFAMultifactor authentication — proving identity with two or more different kinds of evidence
OCSPOnline Certificate Status Protocol — real-time check that a certificate is still valid; "stapling" means the server presents the proof itself (Lesson 0005)
PBQPerformance-based question — an exam question you answer by doing, not choosing
PKIPublic Key Infrastructure — the system that issues, verifies, and revokes certificates (Lesson 0005)
RSARivest–Shamir–Adleman — the classic asymmetric key-pair algorithm (Lesson 0004)
SHASecure Hash Algorithm — the hash family; SHA-256 is today's default fingerprint (Lesson 0004)
TLSTransport Layer Security — encrypts traffic in transit; hybrid: asymmetric handshake, symmetric bulk (Lesson 0004)
VPNVirtual Private Network — an encrypted tunnel across an untrusted network
