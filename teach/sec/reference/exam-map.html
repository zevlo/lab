The five domains

DomainWeightWhat it covers
1. General Security Concepts12%Control categories and types, CIA triad, AAA, non-repudiation, zero trust, change management, cryptography basics
2. Threats, Vulnerabilities & Mitigations22%Threat actors, attack vectors, vulnerability types, malware, password and network attacks, mitigation techniques
3. Security Architecture18%Cloud, virtualization, IoT, industrial control systems, infrastructure as code, data protection, resilience and recovery
4. Security Operations28%Hardening, asset management, vulnerability management, monitoring, firewalls and security tools, identity and access management, automation, incident response, forensics
5. Security Program Management & Oversight20%Governance, policies, risk management, third-party risk, compliance, audits, security awareness

Weekly rhythm (10+ hours in this workspace)

  • End of week: one mixed-review session across everything so far
  • The other ~25–30 hours: Gibson book chapters, Messer videos, Gibson practice questions
