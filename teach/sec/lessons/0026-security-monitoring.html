Part 1 — The feed: logs and where they go

SourceWhat it records
Firewall logsPermits and denies — who tried to cross which boundary, when.
IDS / IPS logsDetections and blocks, with the signature or behavior that fired (Lesson 0018).
Application logsWhat the software itself did — authentication events, errors, transactions.
Endpoint / OS security logsProcess starts, privilege use, logins, changes — the host's own story.
Network logs, flow dataWho talked to whom, how much, when — metadata without payloads.

Two transport names: syslog — the standard protocol devices use to ship event messages to a collector (UDP 514, or TCP/TLS when protected). SNMP traps — the management protocol's push messages: the device reports "something happened to me" without being asked.

How alerts get decided: the detection methods

MethodFires whenThe trade
Signature-basedActivity matches a known pattern.Few false positives; blind to anything novel.
Heuristic / behavioralActivity matches rules about how attacks tend to behave.Catches variations; more tuning, more noise.
Anomaly-basedActivity deviates from a learned baseline.Catches the unknown; the baseline itself is the risk — noisy day one, poisoned day worse.
Trend analysisThe shape over time is wrong — slow drift, low and slow exfiltration.Sees what single events hide.

Lesson 0013's indicators — lockouts, impossible travel, beaconing, consumption against baseline — are exactly what these methods turn into alerts. Monitoring is indicators, industrialized.

Practice — 8 questions, timed

Four marked MULTI-HOP combine frameworks from earlier lessons. One marked BEST ANSWER has two defensible options — pick the better. Budget: 11 minutes for 11 questions — the exam's pace. Stopwatch: 0:00

QUESTION 1

Firewall denies, an IDS signature, and an impossible-travel login arrive as one combined event on one timeline with one alert. Which system, and which capability did the joining?

SIEM; correlation. Aggregate, normalize, correlate — three events from three sources become one story. SOAR would be what fires after the decision: the automated enrichment, ticket, block.

QUESTION 2 MULTI-HOP

No signature exists for the new malware family. Still, the alert fires: the host's outbound volume is four times its learned normal, to a destination it has never called. Which detection method, and which Lesson 0013 indicator is it industrializing?

Anomaly-based; resource consumption. Deviation from a learned baseline — no signature required, which is exactly its value against novel threats. The price: a noisy first week and a poisonable baseline. Consumption-against-baseline was 0013's indicator; monitoring is that indicator, automated.

QUESTION 3

Network gear ships its event messages to a central collector over UDP port 514. Which standard protocol?

Syslog. The event-shipping standard — firewalls, switches, servers all speaking one log dialect to a collector. SNMP is management (and its traps are the device's unsolicited reports); NetFlow is metadata about conversations, not events.

QUESTION 4

Investigators need who-talked-to-whom maps across ten thousand hosts — volumes, timing, destinations — cheaply, without storing any payload. Which source fits?

NetFlow. Metadata at scale: source, destination, ports, bytes, duration — the conversation record without the content. Packet capture gives the bytes themselves: decisive evidence, unaffordable at this scale.

QUESTION 5 MULTI-HOP

Lesson 0013's rootkit edits the local log to hide its tracks. Which two pipeline properties take that option away?

Off-host shipping and encrypted retention. Events leave the compromised host immediately — nothing left to edit — and the stored copy cannot be silently altered. The rootkit's hiding trick works only on logs that stayed home.

QUESTION 6 BEST ANSWER

A suspected exfiltration happened last night. Two capabilities are on the shelf: NetFlow records and a protocol analyzer with full packet capture for that window. The question is exactly what was sent. Which serves better, and why?

Capture — the payload is the evidence. "What was sent" is a content question: only the bytes answer it. The defensible near miss: NetFlow proves the exfil pattern (volume, destination, timing) and is already in hand — but it names the conversation, not the content. Exams ask the question that picks the depth.

QUESTION 7

An organization wants its STIG checks machine-checked instead of eyeballed — vulnerability status and configuration compliance validated automatically against benchmarks. Which standard suite?

SCAP — Security Content Automation Protocol. Standards for automating vulnerability and compliance checking: the machinery under Lesson 0023's compliance scans. CVE names flaws; SCAP automates checking for them.

QUESTION 8 MULTI-HOP

The SIEM correlates a confirmed beaconing pattern to a workstation. Without a human touching it, the system pulls the host's process list, opens a ticket, and pushes a firewall block. Which system ran the playbook — and which earlier lesson's detection fed it?

SOAR; Lesson 0013's indicators. Orchestration, automation, response — the alert-triggered runbook: enrich, ticket, contain. The SIEM correlated and decided; SOAR executed. And the trigger was an indicator of compromise — beaconing, the regular heartbeat of command-and-control — automated end to end.
