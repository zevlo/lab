Part 1 — Mixed quiz: 24 questions, timed, two typed

QUESTION 1

A billing clerk can suddenly open every payroll record. Which attack, and which direction?

Privilege escalation; horizontal. Same privilege level, wrong victims — user reaching into other users' records. Vertical would be the clerk turning admin. (Lesson 0014.)

QUESTION 2

Microsegmentation means a compromised workload can talk to its own service and nothing else. Which zero-trust goal does this implement?

Threat scope reduction. Shrink the blast radius so one foothold reaches little — segmentation is the implementation. (Lessons 0003, 0015.)

QUESTION 3

A crew breaks in quietly, maintains access for five months, and funds it all with ransomware-as-a-service revenue. Which actor best fits?

Organized crime. The tempting distractor is nation-state — but patient dwell is their method, while ransomware-as-a-service with a help desk is crime's business model. Revenue motive wins the best-answer call. (Lesson 0008.)

QUESTION 4

A web form refuses any input containing quote characters and SQL keywords before it ever reaches the database. Which family of fixes is this?

Input validation. Rejecting hostile input at the door — the fix family for SQL injection and cross-site scripting. (Lesson 0011.)

QUESTION 5

A server refuses to run unsigned boot code. Which technique, and which promise does it make?

Secure boot; block what is unsigned. Refusal to run is blocking — secure boot's exact promise. The measured/attestation family records and reports instead. (Lesson 0015.)

QUESTION 6

Overnight, one carefully chosen password was tried against hundreds of accounts. Which indicator surfaces it in the morning?

Widespread account lockouts. One password, many accounts — password spraying, betrayed when lockouts cluster across the directory. (Lessons 0013, 0014.)

QUESTION 8

Production is down and actively exploited; a vendor patch exists. Which path is correct?

Emergency process now, documentation after. Active exploitation is exactly what the emergency path exists for — expedited approval, fix, then the complete record. (Lesson 0006.)

QUESTION 9

The phones run the factory operating system, restrictions intact — but several host applications acquired from outside the vendor's store. What is this called?

Sideloading. The dividing line: sideloading installs from outside the store with the OS untouched; jailbreaking (iOS) and rooting (Android) remove the OS's own restrictions. Factory OS intact = sideloading. (Lesson 0012.)

QUESTION 10

The browser shows the padlock, the URL is correct, but the user arrived at the attacker's site anyway — the name was resolved from a corrupted cache. Which attack?

DNS poisoning. Corrupted resolver cache, trusted name resolving to the wrong address. Domain hijacking would live at the registrar — the account, not the cache. (Lesson 0014.)

QUESTION 11

Two users, identical passwords, different stored hashes. What made that happen, and which goal does it support?

A salt; integrity of stored credentials. Random value mixed in before hashing so identical inputs fingerprint differently — precomputed table attacks lose their leverage. (Lesson 0004.)

QUESTION 12

An email "from the CFO" demands an urgent wire to a new vendor, sent from a look-alike domain. Which attack, and which lever dominates?

Business email compromise; authority. The executive impersonation with a payment redirect is BEC's signature; authority plus urgency are the levers. (Lesson 0010.)

QUESTION 13

Process lists, connections, and file views all lie to the administrator — the concealment lives at kernel level. Which malware, and what is NOT its hiding place?

Rootkit; memory only. Kernel-level concealment is the rootkit. Memory-only hiding is the fileless species — the discrimination the question is really testing. (Lesson 0013.)

QUESTION 14

A legacy Windows 2008 controller can never be patched. Which mitigation is best?

Isolation from the main network. Segmentation is defensible — blast radius shrunk. But "never patchable" is the tell: with no compensating patch path ever coming, removing the network path entirely is the stronger claim. (Lesson 0015.)

QUESTION 15

A user logs in from Chicago; ninety seconds later the same account logs in from Singapore. Which indicator is this?

Impossible travel. Two logins closer together than the flight between them could ever allow — a credential-compromise signature. (Lesson 0013.)

QUESTION 16

Removing the need for a password entirely — passkeys, biometrics — kills which attack family at the root?

Password attacks. No shared secret exists — spraying and brute force lose their target entirely, not just their success rate. (Lessons 0014, 0015.)

QUESTION 18

The change is approved and tested. What does the process demand before anyone touches production?

A tested rollback plan. The way back must exist and must have been proven before the way forward opens. (Lesson 0006.)

QUESTION 19

A database server at end of life receives a vendor patch for one last known flaw. Which pairing is correct?

Known vulnerability; patch closes it. A vendor patch by definition means the flaw was known and fixed — patching's exact territory. Zero-days have no patch; EOL means no more patches at all. (Lessons 0012, 0015.)

QUESTION 20

A container fleet is replaced from clean images every release. Malware lands on one container at noon. What is true at the next deploy?

The infection is discarded with the container. Immutability means replace, never modify — the clean image returns and the modification has nowhere to live. It never blocked execution; it refuses persistence. (Lesson 0015.)

QUESTION 21

An employee stands up an unapproved file-sharing service on company data. Which risk category is this, primarily?

Shadow IT with data exposure. Unapproved tooling moving company data — no malice required, just unmanaged risk. An insider threat implies intent. (Lesson 0008.)

QUESTION 22

A technician receives the hash of a software image and recomputes it locally. Which property is being checked, and what does a mismatch mean?

Integrity; the image was altered. The fingerprint changed, so the content changed — hashing's whole job. (Lesson 0004.)

QUESTION 23

Ransomware note, encrypted files, and a countdown clock. Which IoC family surfaced first if the only alert was CPU and memory pinned at 100 percent?

Resource consumption. Encryption is compute-heavy — consumption against baseline is the early tell before any note appears. (Lesson 0013.)

QUESTION 24

A self-signed certificate serves two lab servers perfectly but fails for every browser. Which missing link explains it?

No trusted root backs the chain. The chain has one link — itself. The servers trust it because they were told to; browsers only climb chains that end at an installed root. (Lesson 0005.)
