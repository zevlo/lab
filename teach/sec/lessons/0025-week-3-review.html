QUESTION 1

A payroll clerk's account can suddenly edit everyone's pay rates — same person, far more power. Which direction of escalation?

Vertical; beyond own role. User rising to admin power. Horizontal is the sideways twin — a user reaching into other users' things at the same level. (Lesson 0014; this pair's scheduled rep.)

QUESTION 2

The ideal control — a dedicated private circuit — is unaffordable, so an encrypted VPN over the internet is deployed instead. Which control type?

Compensating. The substitute when the ideal control is impossible: reduce the risk with what is achievable. (Lessons 0001, 0007.)

QUESTION 3

During the handshake, the server itself hands the client fresh proof that its certificate is still good — the client never queries the certificate authority. Which technique?

OCSP stapling. The server fetches its own status proof and staples it to the handshake — fresh, without every visit leaking a query. (Lesson 0005.)

QUESTION 4

"It sits on the internal VLAN, so it must be safe." Which anti-pattern does this sentence name?

An implicit trust zone. Location granting trust — the exact assumption zero trust exists to eliminate. (Lesson 0003.)

QUESTION 5

A cross-team board reviews every proposed modification for risk and impact, and approves or rejects it before scheduling. Which body?

The change advisory board. The checkpoint between "proposed" and "scheduled" — change management's gate. (Lesson 0006.)

QUESTION 6

A trade forum that defense contractors frequent is infected — no email sent, victims selected purely by community. Which attack, and which actor best fits?

Watering hole; nation-state. Selection by community suits patient espionage — the victims come to the malware. (Lessons 0008, 0014.)

QUESTION 8

"I'm from the help desk and I need your code to close a ticket." The manufactured story itself is called what?

Pretexting. The invented justification — the script. Impersonation is the role being worn; pretexting is the story that makes the ask sound legitimate. (Lesson 0010.)

QUESTION 9

A new cloud instance shows leftover files from the previous tenant — no one attacked anyone. Which vulnerability is this, by mechanism?

Resource reuse, a passive leak. Provider hardware recycled across tenants — prior data arrives with it. VM escape is the active sibling: a guest breaking out to the host. (Lesson 0012.)

QUESTION 10

Malware running inside a legitimate process's memory: nothing on disk to scan, and a reboot clears it out. Which species?

Fileless malware. Memory injection enables it; resting memory reboots fight it. The rootkit hides deep and persists — the opposite trade. (Lesson 0013.)

QUESTION 11

An attacker rides an already-authenticated connection using a stolen token. Authentication was never attacked — it was what?

Borrowed, not attacked. Session hijacking: steal the token, ride the session. Pass-the-hash is its credential sibling — the evidence replayed directly. (Lesson 0014.)

QUESTION 12

Domain name system answers for known-malicious domains are pointed at a dead end, so malware's callbacks never reach home. Which technique?

DNS sinkholing. The defender's move: break command-and-control by answering the malware's own DNS questions with nothing. Poisoning is the attacker's mirror — corrupting a trusted cache. (Lessons 0014, 0015.)

QUESTION 14

Servers are added before the product launch and removed after it. Capacity that grows and shrinks on demand is called what?

Elasticity. Bidirectional — the dividing line with scalability, which only grows one way. (Lesson 0017.)

QUESTION 15

One appliance: application-aware, identity-aware inspection with intrusion prevention built in. Another: many functions bundled in one box for a small office. First and second, in order?

NGFW; UTM. Intelligence versus bundling — the divider from Lesson 0018. A WAF guards one application layer; SASE delivers the whole edge from the cloud.

QUESTION 16

An ingress sits in front of a server pool: terminates TLS, spreads load, hides the backend from the internet. Which appliance, facing which way?

Reverse proxy; inbound. Serves the servers, faces the internet — your ingress controller's exam name. Forward serves users going out. (Lesson 0018.)

QUESTION 17

Backups run: full every Sunday, differential each weeknight. Friday night the disks fail. What does the restore require?

The full and the latest differential. Always exactly two pieces — that is the differential's whole selling point. The incremental chain is the one that grows piece by piece. (Lesson 0019.)

QUESTION 18

The pipeline's database password moves from a plaintext environment variable into a central vault with rotation and access logs. Which practice?

Secrets management. Machine credentials in a vault, rotated and audited. Key management is the cryptographic-key lifecycle — its nearest neighbor and constant distractor. (Lesson 0020.)

QUESTION 19

Honest label for the hotel Wi-Fi page that asks your name and room number before granting access?

Acceptance, not authentication. A captive portal records that someone agreed — it proves nothing. Per-user proof needs enterprise mode and a RADIUS server. (Lesson 0021.)

QUESTION 21

Drives from an internal file server will be wiped and reused by the same team, same data sensitivity, next project. Which rung fits?

Clear. Same custody, same sensitivity: overwrite and reuse. Purge is for leaving custody; destroy for classified; erase protects nothing. (Lesson 0022.)

QUESTION 22

The scanner reports a host clean, but a flaw is present and reachable the whole time. Which outcome, and why is it the dangerous one?

False negative; quiet exposure. The miss that feels like safety. Its mirror, the false positive, wastes effort — annoying, not dangerous. (Lesson 0023.)

QUESTION 23

Two scores sit on one flaw. One measures theoretical severity from a standard formula; the other weighs whether exploitation is actually being seen in the wild. First and second?

CVSS; VPR. How bad it could be versus whether anyone is using it. CVE is the name, NVD carries the number. (Lesson 0024.)

QUESTION 24

Ransomware holds full administrator credentials — including over the backup server. Which property keeps restorable copies no matter what the attacker deletes?

Immutability. Copies that cannot be changed or deleted for a set period — WORM, object lock, an air gap. Replication copies the encryption just as faithfully. (Lessons 0019, 0022.)
