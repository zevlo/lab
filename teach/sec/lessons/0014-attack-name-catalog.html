The Attack-Name Catalog

One win today: attach the right name to any attack description the exam reads you — network, wireless, application, password, cryptographic, or physical. Every item here is one sentence long. The catalog is the exam's list, and the list is the lesson.

Why this matters to your mission

These names are the taxonomy of a security operations center's alert queue — and two of them describe exactly what intruders do inside government networks: pass-the-hash to move without cracking anything, and privilege escalation to turn a toe-hold into ownership. When a DoD 8140 role says "what are we looking at?", the answer starts with a name from this table.

Part 1 — The catalog, grouped by where it strikes

AttackOne-sentence mechanismScenario tell
Denial of service (DoS)Flood or exhaust a service until it cannot answer.One source, one exhausted service.
Distributed DoS (DDoS)The same flood from thousands of machines at once — usually a rented botnet."Traffic from 40,000 addresses in an hour."
DNS poisoningCorrupt a resolver's cache so a trusted name resolves to the attacker's address.The bank's name opens the attacker's site.
Domain hijackingTake over the domain registration itself — all traffic and mail redirect.The registrar account was the target.
On-path attackSit between client and server, reading and altering both directions. (Formerly man-in-the-middle.)Both sides think they talk to each other; they talk to the attacker.
Replay attackCapture valid traffic or credentials, re-send them later — the server cannot tell old from new.An "old ticket" accepted as fresh.
Session hijackingSteal an active session token and ride an already-authenticated connection.Authentication was never attacked — it was borrowed.
Pass-the-hashReplay a captured hash directly as authentication evidence — no cracking.The hash itself logs in.
Evil twinA rogue access point broadcasting a legitimate SSID; laptops auto-join.The café's Wi-Fi, twice — one of them an attacker.
Deauthentication attackForce wireless clients off the network — often to capture the reconnect, or to herd victims toward the evil twin.Everyone dropped, then "reconnected."
RF jammingFlood the radio spectrum so wireless stops working at all.Physical-layer denial: no exploit, just noise.
Privilege escalationGain rights beyond your account's own — vertical (user → admin) or horizontal (user → user).A normal account suddenly empties the admin role.
Directory traversalInput paths like ../../etc/passwd walk out of the web root to read unreachable files.The path, not the payload, is the attack.
Password sprayingOne carefully chosen password tried against many accounts — staying under lockout thresholds.Its signature indicator: widespread account lockouts.
Brute force (password)Many passwords against one account until one works.One account, thousands of attempts.
Downgrade attackTrick a handshake into negotiating older, weaker cryptography — then break the weak version."The connection settled on TLS 1.0."
SSL strippingRemove the padlock before the session starts, downgrading the victim's HTTPS to plain HTTP.The user typed https://; arrived at http://.
RFID cloning (physical)Copy a badge or card's radio identity and replay it.A cloned access badge opens the door.

Part 2 — The discrimination pairs

PairThe dividing line
DoS vs. DDoSOne source versus many — and DDoS implies a botnet behind it.
On-path vs. replayOn-path is a position (between the parties); replay is an action (old data re-sent). An on-path attacker may replay; replay needs no position.
Session hijacking vs. pass-the-hashRide an existing session (hijack) versus manufacture a new login from stolen material (pass-the-hash). Both are replay-family.
Evil twin vs. deauthenticationThe twin is a fake place to connect; deauthentication is the shove that often drives victims there.
Spraying vs. brute forceOne password, many accounts (spraying) versus many passwords, one account (brute force). Lockout patterns reveal which.
Downgrade vs. SSL strippingDowngrade weakens the negotiated protocol; SSL stripping removes encryption before negotiation, at the HTTP layer.

Practice — 8 questions, timed

Four marked MULTI-HOP combine frameworks from earlier lessons. One marked BEST ANSWER has two defensible options — pick the better. Budget: 11 minutes for 11 questions — the exam's pace. Stopwatch: 0:00

QUESTION 1

A service is flooded from forty thousand addresses in one hour; the flood is traced to rented botnet machines. Which attack?

Distributed denial of service (DDoS). Many sources means distributed — and the botnet rental is organized crime's business model (Lesson 0008). One source would be plain DoS; jamming is radio noise, not packets.

QUESTION 2 MULTI-HOP

Users type their bank's correct address, but a corrupted resolver cache opens an attacker's server instead. Attack, and which triad goal is harmed?

DNS poisoning; integrity. The name-to-address mapping was altered — an integrity failure the user cannot see. Confidentiality is the follow-on harm, but the mapping itself is what was tampered with.

QUESTION 3

At a conference, laptops auto-join an access point broadcasting the venue's exact SSID — operated by an attacker. Which attack?

Evil twin. The fake access point wearing the real name. Deauthentication is the shove — forcing clients off so they reconnect (often to the twin); the twin is the destination.

QUESTION 4 MULTI-HOP

An attacker steals an active session token and continues the victim's already-authenticated session. Which attack, and which A of AAA did it sidestep?

Session hijacking; authentication. The login was never attacked — the attacker boarded after it. Authorization still applies to the session; what was skipped was proving who is using it. (Lesson 0002 applied.)

QUESTION 5 MULTI-HOP

A bug in a web app lets a standard user account perform administrator actions. Which attack, and which zero-trust goal would have limited the blast radius?

Privilege escalation; threat scope reduction. User turning admin is escalation (vertical); segmentation plus least privilege — threat scope reduction — is exactly the goal that contains it. (Lessons 0003 and this one: the missed term, new frame.)

QUESTION 6

A web endpoint accepts ../../etc/passwd as a filename and serves a file outside the web root. Which attack?

Directory traversal. The path is the weapon — walking out of the allowed directory. Listed under cloud and application attacks in Lesson 0012's table; today it gets its name.

QUESTION 7 MULTI-HOP

One password is tried against hundreds of accounts overnight, and the morning shows widespread lockouts. Which attack, and which indicator gave it away?

Password spraying; account lockouts. One password, many accounts — designed to stay under any single account's threshold, betrayed when lockouts cluster. Brute force is the mirror image: many passwords, one account. (Lesson 0013's indicator table, applied.)

QUESTION 8 BEST ANSWER

During the handshake, an attacker interferes so the parties settle on an old, weak version of TLS, then breaks it. Which attack is best named?

Downgrade attack. The negotiation itself was manipulated into weaker cryptography — that is downgrade's exact signature. SSL stripping is the tempting distractor: it removes encryption before negotiation, at the HTTP layer, swapping https for http. Here the padlock exists; the crypto behind it was weakened.
