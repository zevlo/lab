Zones, Appliances, Placement

One win today: read any network topology and say what each box is, why it sits there, and what happens when it fails. Placement and failure modes are the exam's favorite angles on this objective — the names alone are not enough.

Why this matters to your mission

This is a day at work in a DoD 8140 role: public-facing services live in screened subnets, every admin path runs through a jump server so the audit trail is complete, and inline prevention devices are configured to fail-close — because in a defense network, a security device that dies open is a breach waiting to be discovered. The exam asks exactly one thing more than your DevOps experience covers: which failure mode, which placement, which direction.

Warm-up — typed recall, no choices

W1 is the measured-boot reframe. The anchor: measured = the TPM writes it down · attestation = someone reads the record · secure and safe = the firmware refuses.

ZoneWhat lives thereThe rule

Connectivity tools that build the zones: VLANs (logical separation on shared switches), VPN tunnels (encrypted crossing of untrusted space), microsegmentation (banked in Lesson 0017), and the air gap — no connection at all.

Practice — 8 questions, timed

Four marked MULTI-HOP combine frameworks from earlier lessons. One marked BEST ANSWER has two defensible options — pick the better. Budget: 11 minutes for 11 questions — the exam's pace. Stopwatch: 0:00

QUESTION 1

Public web servers sit between an outer filtering device and an inner one; a breach there exposes the service but not the internal network. What is that middle zone called?

A screened subnet. The SY0-701 name for the DMZ: public-facing services between two filters. The exam moved to "screened subnet" terminology — know both names.

QUESTION 2 MULTI-HOP

A public web application keeps receiving Lesson 0011's injection attempts. Which appliance filters that input at the application layer before it reaches the code?

Web application firewall. Layer 7, application-specific — SQL injection and cross-site scripting are exactly its filters. A UTM bundles many functions; a packet filter never sees the payload. (Lesson 0011 applied.)

QUESTION 3

Employees' outbound web traffic passes through an intermediary that filters, caches, and hides the client addresses. Which appliance, and which direction does it face?

Forward proxy; outbound. It serves the users going out. Reverse is the mirror: inbound, serving the servers. Direction decides the name.

QUESTION 4 MULTI-HOP

Every administrator reaches production through one hardened, fully logged host. Which appliance, and which AAA element does its log fulfill?

Jump server; accounting. The bastion host concentrates every admin path so every action is recorded — accounting's exact purpose. (Lesson 0002 applied.)

QUESTION 5 MULTI-HOP

A device receives a copy of traffic on a span port and raises alerts but cannot block. Which appliance, and which control type from Lesson 0001?

Intrusion detection; detective. A copy on a span port means out of band — it discovers and reports, which is detective's definition. Inline would make it prevention. (Lesson 0001 applied.)

QUESTION 6 BEST ANSWER

During an active attack, the inline prevention device at a military network's edge loses power. Which failure mode should it have, and why?

Fail-close — security outranks availability. The defensible near miss: fail-open keeps the mission running — right call for a retail web store. A defense network mid-attack chooses dead over open: dropping everything beats passing the attacker through. (This lesson's pairs; Lesson 0001's categories.)

QUESTION 7

A switch port forwards no traffic at all until the connecting device proves its identity. Which mechanism?

IEEE 802.1X. Identity before connectivity, at the jack — via EAP. It is the port-level answer to rogue devices and Lesson 0003's "never trust" applied to physical ports.

QUESTION 8 MULTI-HOP

Branch offices receive their networking and their security stack — filtering, inspection, access policy — delivered together from the cloud. Which model?

Secure access service edge (SASE). Networking plus security converged and cloud-delivered. SD-WAN is the tempting distractor — networking only, no security stack. UTM bundles functions in one on-premises box. (This lesson plus Lesson 0017's responsibility thinking.)
